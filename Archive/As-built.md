- **v8 은 5필드를 한 번에 넣었다**(`mineLevels`·`pendingOreCount`·`crystal`·`tutorial`·`settings`). 나눠 넣었으면 v9 가 한 번 더 필요했다. v7 변환은 전부 "없으면 기본값" — 변환 실패 경로를 만들지 않았다. 이후 확장(`appearance`·`tuned`·`cellX/Y`·`execStateJson`)은 전부 **무버전 확장 필드**로 v8 을 유지했다.
- **표기 계약은 JSON 한 장 + 스칼라 최소**(`MineUpgradeInfoJson` + 레벨 3종). 클라 **재계산 금지** — 파싱만.
- **T-05 자동 실행은 튜토리얼 완화 활성 중 skip** 한다. 안 하면 1단계가 저절로 통과된다 (**J13**).
- **다시 보기는 completed/skipped 를 되돌리지 않는다** — 되돌리면 완화(C1~C3)가 재적용된다. 완화 활성 판정이 그 플래그 둘로만 갈리기 때문.
- **손 용량 3 + 같은 광물 이어 캐기**(2026-08-18 오너 결정, `docs/13` §5.3). 다른 종류 광맥은 소모 없이 실패, 이어 캐기 중 희귀 승격은 그 1회 승격 취소(유실 방지).
- **D-17**: MSW `JSONEncode` 는 **빈 Lua 테이블을 `LEA-3001` 로 거부**한다. 빈 body 제어 블록이 검증기는 통과하는데 직렬화를 죽였고, 기록 실패가 튜토리얼 5단계 무한 실패로 번졌다. 정리 지점은 `SanitizeProgramForJson`/`GetSanitizedProgram` — **새 직렬화 경로는 이 둘을 지나게 할 것.** 교훈: **검증기가 통과시키는 값의 전 범위가 직렬화 경로에도 들어온다.**
- **8단계 골드 보정**: 1회차 + 8단계 + 골드 10 미만이면 서버가 10 으로 채운다(`EnsureWorkerPurchaseFunds`). 다시 보기는 완화 미적용이라 자동 제외.
- **튜토리얼 dim 은 전화면 Dimmer 를 쓰지 않는다** — 최상위 그룹의 전화면 스프라이트는 반드시 모든 UI 를 덮는다. `Root/Dimmer` 를 끄고 per-button 잠금 dim + 화살표 + 툴팁으로 대체(`docs/19` §6.1 개정).
- **잠금 목록은 "정상 경로"만이 아니라 "막혔을 때 푸는 버튼"까지 포함해야 한다** — 7단계에 `보호분 판매` 토글이 빠져 판매 완료가 구조적으로 불가능했다.
- **화살표 seq 에 같은 버튼을 연속으로 넣지 말 것** — 진행돼도 화살표가 같은 자리라 "반응 없음"으로 보인다.

### M5. T-08·T-11·T-12·T-13·T-14 + F9 (2026-08-14 ~ 08-21)

UI 아이콘 · 일꾼 시작점 분산 · BGM/설정 패널 · UI 파츠 · 블록 편집기 개편 · 성능 기준.

- **T-11 시작점 분산이 밸런스 구조를 바꿨다**: 시작 셀이 창고에 뭉쳐 있어 복사한 프로그램의 첫 `동 E` 가 광맥에 닿지 않았다 → **"앞"은 서쪽 인접 칸**으로 확정하고 3맵 재배치. 그 결과 **P1 왕복이 일꾼 수에 비례**(30→111)하고 P2 순회(95)를 앞질러, "튜토리얼이 가르치는 왕복이 상위 전략"이 됐다.
- **초보 광산 10×10 확장(2026-08-21)**: 광맥 6개(rt 5/8/8/8/6/15)로 상한을 121/분에 묶었다(깊은 광산 돌 90/분 역전 방지). ⚠ **`(0,0)` 창고·`(1,0)` 1번 광맥은 `TutorialController` 하드코딩 앵커라 불변.**
- **T-14 블록 스트립**: 자연어 전면 삭제. 스트립은 트리를 **평탄 토큰으로 펴되 각 토큰이 원본 노드 참조를 든다** — 클릭 삭제가 인덱스 재계산 없이 트리를 직접 수술한다. 열린 제어 블록은 `]` 칸을 내지 않는다. ⚠ `RenderList` 는 편집기에서 안 쓰지만 **라이브러리 상세 미리보기가 소비한다 — 지우면 안 된다.**
- **`ProgramState` 3값**(`Idle`/`Running`/`Stopped`, C217). `ResetExecution` 은 항상 `Idle` 로 착지하고 **정지 계열 호출자만 뒤에서 덮어쓴다** — 안에 갈래를 만들면 실행할 때마다 램프가 빨갛게 튄다.
- **`settings.tuned` 무버전 확장**: T-02 마이그레이션이 박아 둔 초안값(0.5/1.0)이 C220 확정값(0.8/0.7)을 덮지 않도록, 슬라이더로 저장한 적 없으면 저장 볼륨을 버리고 설계 기본값을 쓴다. **교훈: 마이그레이션 기본값과 사용자 선택을 구분할 수단이 없으면 나중 확정값이 영영 무시된다.**
- **`PlayBGM` 은 루프다**(실측). 볼륨 0 은 Pause, 복귀는 Resume — **`PlayBGM` 재호출 금지**.
- **F9 성능**: 최악 부하에서도 틱 2.494~2.502/s, 서버·클라 54~58fps, 100ms 초과 프레임 0. **성능은 병목이 아니었고 실질 발견은 로그량**(분당 ~1,300건) → `MineLogPolicy`(`Verbose=false` 기본)로 플래그화. ⚠ **판정선 5번(cue `play`→`suppressed` 짝)이 게이트 대상 로그에 얹혀 있다** — 재측정 시 `docs/24` §6 절차 3번의 `Verbose=true` 를 반드시 밟는다. **교훈: 로그를 줄일 때는 "그 로그를 판정 근거로 쓰는 문서"를 먼저 grep 한다.**
- **3맵 시뮬레이터는 플레이어 부재와 무관하게 전부 2.5틱/s 로 병렬 구동**된다 — 서버 부하 모델은 항상 "3심 + 등록 일꾼".
