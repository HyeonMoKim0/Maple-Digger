# D3. 자원 · 인벤토리 기획서 (MVP 통합)

> 최신 결정 기준: [10-MVP-성장-경제-통합명세.md](10-MVP-성장-경제-통합명세.md) (D7). 질문별 근거는 [11-MVP-결정-질문답변-로그.md](11-MVP-결정-질문답변-로그.md) (D8). 이 문서는 D7의 자원 흐름과 저장 계약을 구현 단위로 풀어 쓴다.

## 1. 범위와 원칙

- 광물은 **광맥 → 일꾼 손 → 수레 → 해당 광산 창고(Depot) → 계정 창고(AccountStorage)** 순서로 이동한다.
- 자동화 프로그램은 손·수레·광맥을 조작하며, 판매·맵 해금·강화·외형은 계정 자원을 소비한다.
- 모든 계정 자산은 영구 저장한다. 단, 일반/특별 광맥의 현재 매장량과 특별 광맥 출현은 플레이 세션 한정이다.
- 서버가 광맥, 운반, 창고 입고, 판매와 재화를 판정한다. UI는 읽기와 명시적 요청만 담당한다.

## 2. 자원 분류

| 분류 | ID | 사용처 | 저장/판매 규칙 |
|---|---|---|---|
| 일반 광물 | `stone`, `iron`, `gold` | 판매, 일꾼 구매, 맵 해금·강화, 외형 제작 | 계정 창고에 누적. 수동 판매와 자동 초과분 판매 가능 |
| 희귀 광물 | `rare_stone`, `rare_iron`, `rare_gold` | 도감, 계정 영구 패시브 | 각 광물 5회 최초 입고까지 판매 불가. 이후 선택적으로 판매 가능 |
| 재화 | `gold` | 일꾼·수레·맵 강화 및 다음 맵 해금 비용 | 계정 영구 저장 |
| 재화 | `crystal` | 외형 가챠·외형 관련 비용 | MVP에서는 테스트 상점/과제 등 무료 획득만 |
| 재화 | `mine_token` | 광산 맵 해금 조건·해금 광산 강화 | 희귀 광물 판매·과제 등으로 획득 |

일반 광물의 시작 판매 기준값은 돌 1, 철 5, 금 20 골드다. 이는 10~15분 플레이 목표용 초안이며 플레이 테스트로 조정한다.

## 3. 광산별 일반 광물

| 광산 | 일반 광물 | 대표 강화 효과 |
|---|---|---|
| 초보 광산 | 돌 | 광물 획득량 |
| 깊은 광산 | 돌, 철 | 광맥 회복 속도 |
| 보석 광산 | 돌, 철, 금 | 희귀 광물 확률 |

이전 광산의 일반 광물은 다음 광산에도 계속 등장한다. 각 일반 광맥은 하나의 `oreType`과 `stage`를 가지며, `stage`는 채굴 때 감소하고 해당 광산의 회복 규칙에 따라 회복한다.

## 4. 운반 상태 전이

| 위치 | 소유 | 용량/수명 | 들어오는 액션 |
|---|---|---|---|
| 광맥 | 현재 광산 세션 | stage 0~최대 단계, 세션 종료 시 초기화 | 자연 회복 |
| 일꾼 손 | 일꾼별 영구 상태 | 1개 | `mine` |
| 수레 | 일꾼별 영구 상태 | 기본 20, 강화로 최대 50, 도감 보너스 별도 | `load` |
| Depot | 현재 광산의 입고 지점 | 플레이 중 표시용 합계 | `unload` |
| AccountStorage | 계정 | 무제한 | Depot 입고 즉시 반영 |

| 액션 | 성공 조건 | 성공 결과 | 실패 결과 |
|---|---|---|---|
| `mine` | 광맥 stage ≥ 1, 손 비어 있음 | stage -1, 손에 해당 광물 1개 | `hand_full` 또는 `vein_empty` |
| `load` | 손에 광물, 수레 여유 | 수레 +1, 손 비움 | `hand_empty` 또는 `cart_full` |
| `unload` | Depot 셀, 수레 비어 있지 않음 | 수레 전량을 Depot·AccountStorage에 입고 | `not_at_depot` 또는 `cart_empty` |

희귀 광물도 같은 손→수레→Depot 흐름을 따른다. **Depot 입고 순간** 획득 횟수와 영구 패시브를 판정하며, 패시브 연출 때문에 자동화가 멈추면 안 된다.

## 5. 판매와 보호 수량

- 일반 광물은 상점에서 수량을 직접 입력하거나 빠른 버튼으로 판매한다.
- 자동 판매는 플레이어가 켠 경우에만 동작하며, 설정한 보호 수량을 넘긴 일반 광물만 판매한다.
- 기본 보호 수량은 다음 맵 해금에 필요한 일반 광물의 정확한 필요량이다.
- 플레이어가 보호 대상까지 팔고자 하면, 해금 진행이 늦어질 수 있다는 경고를 띄운 뒤에만 판매한다.
- 희귀 광물은 동일 광물을 5회 Depot에 입고하기 전에는 수동·자동 판매 모두 불가하다. 6회째부터 판매 설정이 가능하며, 판매 보상은 골드와 크리스탈 조각이다.

## 6. 희귀 광물과 영구 패시브

- 일반 광맥 채굴마다 희귀 광물 드롭을 판정한다. 기본 확률은 일반 광맥 1%, 특별 광맥 5%다.
- 희귀 돌·철·금은 각 1종이며 효과는 광물마다 다르게 설계한다. 수레 용량, 일반 광물 판매가, 광맥 회복, 희귀 확률을 핵심 후보로 한다.
- 각 희귀 광물의 패시브는 계정 전체에 적용되고 최대 5회 누적된다. 5회 이후의 획득은 화폐 보상으로 전환한다.
- 1회당 효과 수치는 3~5% 범위에서 밸런싱하며, 광물별 최종 효과표는 플레이 테스트 전 확정한다.

## 7. HUD·창고 UI

| 화면 | 반드시 보여 줄 정보 |
|---|---|
| 게임 HUD | 현재 광산, 광산 강화 레벨, 일반 광물 3종 보유량, 골드·크리스탈·토큰, 선택 일꾼의 손/수레, 일꾼별 실행 상태 |
| 창고/상점 | 계정 창고 수량, 판매 수량 입력·빠른 버튼, 자동 판매 토글·보호 수량, 희귀 광물 판매 잠금 진행도 |
| 광산 선택 | 대표 광물, 해금 상태, 강화 레벨, 특별 광맥 출현 정보 |
| 도감/패시브 | 희귀 광물 최초 입고·누적 횟수와 적용 중인 영구 효과 |

중요한 입고·희귀 드롭·판매만 토스트와 효과로 표현한다. 평상시 반복 입고는 HUD 수치 갱신만으로 충분하다.

## 8. 저장·복구 계약

| 데이터 | 저장 시점 |
|---|---|
| AccountStorage, 재화, 판매 설정, 희귀 획득·패시브 | Depot 입고·판매·효과 획득 등 중요 거래 즉시 |
| 일꾼의 손·수레·수레 강화, 프로그램 | 변경 시 및 주기 저장 |
| 광산 해금·강화 | 결제 성공 시 즉시 |
| 광맥 stage·특별 광맥 | 저장하지 않음; 세션 종료 후 초기화 |

저장 실패 시 중요한 거래는 즉시 취소하고 비용을 돌려준다. 이전 저장본을 백업한 뒤 버전을 변환하며, 복구 실패 시 플레이어에게 `복구` 또는 `포기`를 선택하게 한다. 재시도는 사용자의 버튼으로만 실행한다.

## 9. MVP 수용 기준

| # | 시나리오 | 기대 결과 |
|---|---|---|
| R1 | 세 광산에서 각 배치 광물을 채굴 | 돌/철/금이 올바른 계정 창고 항목으로 입고 |
| R2 | 손→수레→Depot `unload` | 수레 전량이 Depot와 AccountStorage에 반영, 재접속 후 복구 |
| R3 | 수레가 가득 찬 상태의 `load` | 손의 광물은 보존되고 자동화는 다음 명령을 계속 처리 |
| R4 | 보호 수량을 넘긴 자동 판매 | 초과분만 골드로 판매 |
| R5 | 보호 수량을 팔기 시도 | 경고 후 승인할 때만 판매 |
| R6 | 희귀 광물 1~5회 입고 | 판매 잠금, 패시브 누적과 중요 연출 발생 |
| R7 | 희귀 광물 6회째 이후 판매 | 설정 시 골드·크리스탈 조각 보상 |
| R8 | 종료·맵 이동·재접속 | 계정 자산·수레·프로그램은 복구, 광맥/특별 광맥은 초기화 |

## 부록. 프로토타입 검증 이력 (2026-07-19)

초기 `farm01`의 돌 1종, 수레 20, 세션 공용 Depot 구현에서는 손·수레·하역·광맥 회복과 HUD 표시를 Maker에서 검증했다. 해당 이력은 현재의 다광산·계정 저장 수용 기준을 대신하지 않는다. 관련 구현은 `VeinTickSimulator`, `WorkerController`, `MineInventoryController`에 남아 있다.
