# 아이디어. 곡괭이 강화 — 채광력 · 행운력 · 광맥 체력

> 2026-08-23 오너 아이디어 기록. **MVP(C212) 범위 밖 — 구체화 전 아이디어 단계**이며 구현 계약이 아니다.
> 구체화 시 F7-B(`13-경제-진행-기능명세.md`)의 강화 체계(수레 강화 · 맵 강화 0~10)와 같은 형식의 기능 명세로 승격한다.
> 용어는 D0(`01-테마전환-용어집.md`)과 충돌하지 않게 확정 후 반영한다.

## 1. 개요

일꾼이 곡괭이로 광맥을 캐는 현행 구조(틱당 1액션, 채굴 1회 = 광물 1개)에 **곡괭이 강화** 축을 추가한다. 강화는 **일꾼마다 개별**로 이루어지며, 두 갈래를 가진다.

| 강화 갈래 | 효과 요약 |
|---|---|
| **채광력 강화** | 한 번 캘 때 광맥에 주는 피해량 증가 → 광물 1개를 얻는 데 걸리는 틱 시간 단축 |
| **행운력 강화** | 광물 획득 시 확률적으로 **+1개 추가 획득** |

이를 위해 새 개념 두 가지가 생긴다: 곡괭이의 **채광력**, 광맥의 **광맥 체력**.

## 2. 채광력과 광맥 체력

- 모든 광맥은 **광맥 체력**을 가진다. 채굴 1회마다 광맥 체력이 **채광력 값만큼 감소**하고, **0 이하가 되면 광물을 획득**한다.
- 첫 번째 맵(초보 광산)은 광맥 체력이 전부 **1**, 곡괭이 기본 채광력도 **1** → 현행과 동일하게 "채굴 1회 = 광물 1개"가 유지된다(하위 호환).
- 상위 맵에서는 광맥 체력을 1보다 크게 두어, 채광력을 올릴수록 광물 1개당 소요 틱이 줄어드는 구조를 만든다.
- **오버킬 확정(2026-08-23)**: 채광력이 광맥 체력을 초과해도 **획득은 1개**다. 초과 피해분은 버리며, 채광력의 효과는 어디까지나 "광물 1개 획득 속도 단축"이다(수량 증가는 §3 행운력의 몫).

**채광력 레벨 규칙**

| 항목 | 값 |
|---|---|
| 기본 채광력 | 1 |
| 최대 레벨 | 10 |
| 레벨당 증가량 | +1 (Lv10 = 채광력 10) |

## 3. 행운력

- 광물 **1개를 획득하는 시점**에 행운력 확률을 판정하여, 당첨되면 **추가로 1개를 더** 얻는다.
- 판정은 획득 건마다 독립.

**행운력 레벨 규칙**

| 항목 | 값 |
|---|---|
| 기본 레벨 / 확률 | Lv1 = 1% |
| 최대 레벨 | 30 |
| 레벨당 증가량 | +1%p (Lv30 = 30%) |

## 4. 강화 재화

강화 비용은 세 종류 재화를 조합한다. **구체 수치(레벨별 요구량)는 구체화 단계에서 확정**한다.

| 재화 | 비고 |
|---|---|
| 골드 | 오너 표현은 "메소" — 프로젝트 확정 용어는 골드(D0 기준)이므로 골드로 기록 |
| 광물 | 레벨이 높아질수록 요구 **개수와 종류**(돌→철→금 등)가 상향 |
| 토큰 | 현재 맵(광산) 강화 전용 재화를 곡괭이 강화에도 사용할 수 있게 확장 |

## 5. 기존 시스템과의 접점 (구체화 시 확인)

- **강화 단위**: 수레 강화·맵 강화와 달리 **일꾼별** 강화다. 일꾼 2~5 확장(F7-B §3)과 결합 시 일꾼당 강화 상태를 프로필에 저장해야 한다 → F7-A 저장 스키마 확장 필요.
- **틱 시뮬레이터**: 광맥 체력·채광력 적용 지점은 `VeinTickSimulator`의 채굴 처리. 맵 강화 보너스 캐시 방식(맵 진입 시·강화 성공 시에만 갱신, docs/13 §5.3)과 같은 패턴을 따르는 것이 자연스럽다.
- **서버 권위**: 판정(행운력 당첨 포함)과 비용 차감은 서버 단일 거래 — 기존 판매·강화 계약(docs/13 §2·§5.5)과 동일 원칙. 거절 사유는 docs/23 카탈로그에 코드 추가.
- **밸런스**: 광물 공급량이 직접 늘어나는 시스템이므로 docs/22 밸런스 모델(공급 상한·처리량) 재계산 대상.

2. 맵별 광맥 체력 값 — 깊은/보석 광산과 특별 광맥의 체력을 얼마로 둘지.
3. ~~오버킬 처리~~ — **확정(2026-08-23)**: 초과분 버림, 광물 1개만 획득. 채광력은 획득 속도 단축 전용(§2 참조).
4. 행운력 추가 획득분의 희귀 광물 판정·수레 적재 상호작용(수레 가득참 시 처리).
