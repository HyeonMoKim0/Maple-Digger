# UI 파츠 2차 제작 목록

> 작성일: 2026-08-18. 근거: `.ui` 전 파일 RUID 전수 조사 + `.mlua` 런타임 스왑 상수 대조 (T-12-B 세션 실측).
> **이 문서는 "새로 그려야 할 원본 PNG"의 단일 목록이다.** 1차 48장(`docs/ui-parts/`)에 원본이 이미 있는 미업로드 파츠는 §4 — **다시 그리지 않는다**, 업로드·배선만 남았다.
> 완성된 PNG 는 `docs/ui-parts/` 에 아래 파일명 그대로 넣는다. 이후 가공(`node tools/ui_parts_prep.cjs`)·업로드(`hyNDP`)·RUID 대장(`docs/26`) 기입·`.ui` 배선은 AI 세션 몫이다.

---

## 1. 공통 스타일 규칙 (1차와 동일 — 지키지 않으면 기존 화면과 톤이 갈린다)

- **RGBA PNG, 바깥 여백 투명.** 해상도는 넉넉히(1000px+) — 가공 도구가 알파 bbox 트리밍 + 역할별 축소를 한다.
- **텍스트·숫자·아이콘을 굽지 않는다.** 문구는 전부 `.ui` 의 `TextGUIRendererComponent` 가 얹는다.
- **도트 외곽선 + 제한된 흙색 팔레트**(크림·양피지·꿀·나무·흙). 금색 광택·네온 그라디언트·가챠식 번쩍임 금지.
- **9-slice 파츠는 모서리 장식을 모서리에만, 테두리 두께를 균일하게.** 가운데는 무지 영역이어야 늘려도 안 깨진다.
- 기존 파츠와 나란히 놓일 것이므로 `docs/ui-parts/` 의 1차 파츠(특히 `modal-frame-blank` · `button-slate-blank` · `ledger-row-resource-blank`)를 참고 이미지로 쓴다.

## 6. 도착 후 처리 절차 (T-12-B 슬라이더 파츠와 동일)

1. PNG 를 `docs/ui-parts/` 에 위 파일명으로 저장 (README 파츠 목록에도 행 추가)
2. `node tools/ui_parts_prep.cjs <이름조각>` — 트리밍 + 역할별 축소
3. `hyNDP` 그룹 저장소 업로드 → 9-slice 파츠는 border 메타데이터 등록 (⚠️ `asset_update_resource_storage_info` 는 name/description/subcategory/properties **4개 항상 함께** — docs/17 함정 9)
4. `docs/26` RUID 대장 기입 → UIBuilder 로 `.ui` 배선 → refresh → Play 스크린샷 판정
