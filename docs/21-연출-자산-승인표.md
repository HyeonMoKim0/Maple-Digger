## 1. 광맥 — 핵심 발견

검색 결과 **광맥 stage 표현에 그대로 쓸 수 있는 자산 2개**를 찾았다. 둘은 역할이 달라 **함께 쓰는 것**을 권한다.

**제안 매핑** — 어느 condition이 "많이 남은" 상태인지는 썸네일 확인이 필요하다(§6 미결 1).

### 1.3 광물 3종(돌·철·금) 구분 방법 — 결정 필요

위 두 자산은 **광물 종류 구분이 없다.** Q1-ⓐ를 문자 그대로 지키려면 `oreType × stage` **12개 서로 다른 스프라이트**가 필요한데, 그런 자산군은 검색으로 찾지 못했다.

| 방안 | 내용 | 평가 |
|---|---|---|
| **A** | `부유석` condition 4개를 stage로 쓰고, **광물 종류는 `SpriteRendererComponent.Color` 색조로 구분** (돌=회색 / 철=청회색 / 금=황금색) | 자산 제작 0. 단 Q1-ⓐ의 "형태로 구분"이 stage에만 적용되고 **광물 종류는 색으로만** 구분된다 → D5 §8 **V1**("광물 종류와 네 상태가 **색 외의 형태로** 구분")을 광물 축에서 어긴다 |
| **B** | `msw-painter`로 **12개를 직접 제작** | V1을 완전히 충족. 제작 비용이 크다(픽셀아트 12장) |
| **C** | 절충 — stage는 `부유석` condition, **광물 종류는 광맥 위에 작은 광물 아이콘 뱃지**를 겹쳐 표시 (docs/20에서 승인한 광물 아이콘 3개를 재사용) | 자산 제작 0이면서 종류가 **형태로** 구분된다. D5 §3의 "작은 아이콘"이라는 표현과도 일치 |

**추천: C.** D5 §3이 일반 광맥의 표현을 "돌/철/금의 형태·색·**작은 아이콘** + stage 0~3 크기·균열·광택 변화"로 규정하고 있어, 아이콘 뱃지는 기획 원문에 이미 들어 있는 방식이다. 승인된 아이콘(`docs/20` §0)을 그대로 재사용하므로 추가 검색도 필요 없다.

## 4. 일꾼 (Q2 — 아바타 기반)

현재 일꾼은 **임시 몬스터 스프라이트**다. D5 §3은 "MSW 아바타 기반 실루엣"을 요구한다.

**방향**: `Worker` 모델을 `AvatarRendererComponent` + `CostumeManagerComponent` 기반으로 바꾸고, 광부 느낌의 기본 외형을 지정한다.

| 슬롯 | 검색 키워드 | 비고 |
|---|---|---|
| `cap` | "광부 헬멧", "안전모", "밀짚모자" | 광부 정체성을 가장 잘 전달 |
| `coat` / `longcoat` | "작업복", "멜빵바지" | |
| `weapon` | "곡괭이", "픽" | 채굴 도구. 손에 들면 역할이 즉시 읽힌다 |

**T-06(외형·도감·가챠)과 겹친다.** 이 티켓에서는 **기본 외형만** 지정하고, 피스 수집·장착 시스템은 T-06에 남긴다. 아바타 슬롯 매핑과 애니메이션 파이프라인은 `msw-avatar` 스킬 문서를 따른다.

> **미검색.** T-04 착수 시 `searchAvatarItems`로 위 3슬롯을 찾는다. 기본 아바타 RUID는 `getAvatarDefaults`로 얻는다.

## 6. 미결 사항

| # | 항목 | 필요한 결정 |
|:-:|---|---|
| 1 | `부유석` condition 1~5 중 **어느 것이 "많이 남은" 상태**인가 | 썸네일 6장을 눈으로 확인해야 stage 매핑을 확정할 수 있다. `getResource`의 `payload.thumbnail` URL을 브라우저로 열어 비교 |
| 2 | **§1.3의 광물 종류 구분 방안** (A 색조 / B 12개 제작 / C 아이콘 뱃지) | **C 추천.** 이 결정이 T-04의 규모를 가장 크게 바꾼다 |
| 3 | 일반 광맥 = `부유석`, 특별 광맥 = `신비한 광석` 배정이 맞는가 | 썸네일 확인 후 판단 |
| 4 | 광맥 크기 | `부유석` 80×144는 세로로 길다. RectTile 한 셀에 놓기에 적절한지 확인 필요. `신비한 광석` 108×80이 셀에 더 맞을 수 있다 |
| 5 | `animationclip`을 `SpriteRUID`에 직접 넣을 것인가 | 넣으면 프레임이 재생된다(광맥이 살짝 움직임 — 의도라면 좋다). 정적으로 두려면 `sprite` 타입 요소를 따로 찾아야 한다. `msw-sprite-ruid` 스킬 참조 |
