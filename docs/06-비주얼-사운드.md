# D5. 비주얼 · 사운드 폴리싱 기획서 (MVP 통합)

> 기준: D7의 MVP 범위와 [07-광산-맵-콘텐츠.md](07-광산-맵-콘텐츠.md) (D6). 비주얼은 게임 원장을 변경하지 않으며, 중요한 결과만 또렷하게 전달한다.

## 1. 목표

플레이어가 한눈에 광맥의 상태, 일꾼의 동작, 수레·창고의 성과, 특별 광맥의 기회를 판단하게 만든다. 목표 미술 톤은 밝고 읽기 쉬운 메이플풍 광산이며, 배경은 저채도·상호작용 대상은 명확한 윤곽과 대비를 쓴다.

## 2. 정보 우선순위

1. 특별 광맥·희귀 광물·중요 보상
2. 일반 광맥 상태와 일꾼의 현재 행동
3. Depot 입고·창고/수레 수치 변화
4. 광산 해금·강화·외형·도감 화면의 선택 정보
5. 장식과 반복 연출

반복되는 채굴·적재·회복은 짧고 조용하게 처리한다. 희귀 광물 입고, 특별 광맥 출현, 하역·판매의 주요 결과만 토스트·위치 표시·HUD 아이콘으로 강조한다.

## 3. 월드 오브젝트

| 대상 | 표현 | 필수 판독 정보 |
|---|---|---|
| 일반 광맥 | 돌/철/금의 형태·색·작은 아이콘 + stage 0~3 크기·균열·광택 변화 | 광물 종류, 채굴 가능 단계 |
| 특별 광맥 | 전용 스프라이트, 반짝임, 효과음, 지도/HUD 위치 | 일반 광맥보다 높은 희귀 기회 |
| Depot | 목재 상자/광차 형태, 하역 순간 짧은 반짝임 | 하역 위치 |
| 일꾼 | MSW 아바타 기반 실루엣, 이동·채굴·적재·하역 반응 | 어느 일꾼인지, 현재 행동 |
| 선택 일꾼 | 발밑 링/얇은 테두리 | 편집기·HUD 대상과 일치 |
| 수레 | 용량 강화가 읽히는 외형 단계 또는 UI 표기 | 적재량과 용량 |

광맥 stage는 0(고갈)~3(만재)에서 색상만이 아니라 크기·균열·반짝임을 함께 바꾼다. 회복은 단계당 0.25초 내 작은 반짝임, 채굴은 0.3초 내 파편 효과로 끝낸다.

## 4. HUD와 주요 화면

| 화면 | 시각 요구사항 |
|---|---|
| 게임 HUD | 현재 광산·강화 레벨, 돌/철/금, 골드·크리스탈·토큰, 선택 일꾼 손/수레, 최대 5명 실행 상태 |
| 프로그램 편집/라이브러리 | 대상 일꾼, 실행/정지 상태, 저장 프로그램 목록과 슬롯 수 |
| 광산 선택 | 대표 광물, 해금 상태, 강화 레벨, 마우스 오버 특별 광맥 정보 |
| 상점/창고 | 판매·자동 판매 보호 수량, 재화 증감, 희귀 판매 잠금 |
| 외형/도감 | 헤어·얼굴·의상 피스, 희귀도·확률, 50회 보장, 도감 수레 보너스 |

월드 오브젝트를 가리는 큰 안내문은 쓰지 않는다. 실패 원인은 블록 패널과 간결한 토스트로 안내한다.

## 5. 외형 연출

- 기본 외형과 보유 피스를 헤어·얼굴·의상으로 자유 조합한다. 외형은 모든 일꾼이 공유하되 장착은 일꾼별로 보여 줄 수 있다.
- 피스 희귀도는 일반/고급/희귀/영웅/전설의 5단계다. 최초 획득·전설·장착 변경을 우선 연출한다.
- 가챠는 플레이어가 고른 부위에서 실행하며 세 부위가 공유하는 50회 보장 카운터를 보여 준다.
- MVP에서는 무료 크리스탈 획득만 제공한다. 유료 뽑기·결제 연출은 제외한다.

## 6. 사운드

| Cue | 트리거 | 중복 제한 |
|---|---|---|
| `mine_hit` | 채굴 성공 | 일꾼별 0.25초 |
| `mine_empty` | 고갈 채굴 실패 | 선택 일꾼만, 0.8초 |
| `cart_load` | 적재 성공 | 일꾼별 0.25초 |
| `depot_unload` | 하역·중요 입고 | 같은 틱 1회 |
| `special_vein_spawn` | 특별 광맥 출현 | 스폰 묶음당 1회 |
| `rare_ore_unload` | 희귀 광물 Depot 입고 | 입고 건당 1회 |
| `vein_recover` | 화면 내 광맥 단계 상승 | marker별 1초 |

효과음은 클라이언트가 확정된 게임 이벤트에 반응해 재생한다. BGM 정식 제작은 핵심 상호작용의 판독성을 확인한 뒤로 미룬다.

## 7. 자산 승인표

| 자산군 | 수량 기준 | 승인 기준 |
|---|---|---|
| 광산 바닥/벽 | 광산 테마 3세트 | 반복 이음새가 눈에 띄지 않고 광맥·일꾼과 명도 충돌 없음 |
| 일반 광맥 | 광물 3종 × stage 4 | 100% 크기에서 상태·종류 구분 가능 |
| 특별 광맥 | 1세트 이상 | 일반 광맥과 즉시 구분, 위치를 과도하게 가리지 않음 |
| Depot/수레 | 각 1세트 이상 | 하역·적재 위치와 용량 의미가 읽힘 |
| 일꾼/외형 | 기본 + 부위별 피스 | 5명 동시 표시에서도 식별 가능 |
| UI 아이콘 | 광물·재화·손·수레·상태 | 24px 이상에서 의미가 명확함 |
| 효과음 | 위 cue 전부 | 동시 재생 시 피로감·왜곡 없음 |

RUID는 승인된 리소스 설정에만 기록한다. 빈 RUID를 사용하거나 스크립트에 RUID 문자열을 중복하지 않는다.

## 8. MVP 수용 기준

| # | 시나리오 | 완료 조건 |
|---|---|---|
| V1 | 돌/철/금 stage 0~3 | 광물 종류와 네 상태가 색 외의 형태로 구분 |
| V2 | 최대 5명 동시 동작 | 선택 대상·행동·수레 상태가 읽히고 연출 과밀 없음 |
| V3 | 하역·판매·희귀 입고 | 중요 수치 변화와 월드/HUD 효과가 같은 결과를 가리킴 |
| V4 | 특별 광맥 출현 | 전용 연출, 토스트, 지도/HUD 위치 표시 일치 |
| V5 | 외형 획득/장착/50회 보장 | 희귀도와 도감·보장 상태가 혼동 없이 표시 |
| V6 | PC 1920×1080 | 블록 패널, HUD, 월드 요소가 상호 가리지 않음 |
