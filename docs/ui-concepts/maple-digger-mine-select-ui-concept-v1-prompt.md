# Maple-Digger MineSelectUI 시안 v1 생성 기록

## 목적

`MineSelectUI/SelectPanel`의 광산 선택·해금·강화 정보 구조를 기존 밝은 v2.2 UI 스타일로 정리한 1920×1080 시안이다. 판매·수레·희귀 패널은 같은 화면에 중첩하지 않고 하단 진입 버튼으로만 표현했다.

## 화면 구성

- Beginner Mine / Deep Mine / Gem Mine 3개 카드
- 해금 여부, 대표 광물, 현재 `Lv.n / 10`, 입장 버튼
- 잠긴 광산의 해금 요구 재화
- 선택 광산의 주 효과·기타 효과·다음 강화 비용
- 특별 광맥 활성 수와 최근 셀 좌표
- Sell / Cart / Rare / Tutorial Replay 진입 버튼

## 시각 규칙

- 선택 카드는 밝은 금색 글로우로 강조한다.
- 입장·강화는 녹색, 일반 이동은 파랑, 잠김은 크림·회색 비활성 상태를 쓴다.
- 세 광산 썸네일은 따뜻한 초보 광산, 청회색 깊은 광산, 보라·파랑 보석 광산으로 구분한다.
- 중앙 모달은 하나만 표시하고 배경은 dim 처리한다.

## 구현 경계

- Select / Sale / Cart / Rare / Upgrade 패널은 동시에 켜지지 않는다.
- 강화 수치와 비용은 서버 계산 결과를 표시하며 클라이언트에서 재계산하지 않는다.
- 맵 강화는 문서 계약에 포함되지만 현재 구현 완료로 간주하지 않는다.
