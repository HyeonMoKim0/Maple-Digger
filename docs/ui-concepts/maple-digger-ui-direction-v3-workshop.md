# Maple-Digger UI 방향 v3 — 작업장형 광산 운영 UI

## 목표

기존의 밝고 귀여운 시안을 버리는 것이 아니라, `Maple-Digger`의 핵심인 **블록 자동화·광산 운영·계정 원장**이 먼저 읽히도록 UI의 시각 언어를 재정의한다.

## 핵심 인상

- 귀여움: 광부 아바타와 리소스 아이콘에만 남긴다.
- 기능성: 패널·수량·상태·경로·셀 좌표가 우선이다.
- 세계관: 보물상자보다 작업대, 장부, 광산 노선표, 철제 고정구를 사용한다.

## 시각 규칙

### 표면과 프레임

- 숯색 철판, 낡은 작업지, 목재, 구리색 고정구
- 얇은 구분선과 작은 리벳
- 과도한 금색 베벨, 광택, 별·반짝임은 제거
- 모서리는 둥글게 유지하되 카드형 모바일 UI처럼 과장하지 않음

### 색상

- 기본: `#273038`, `#3D4A4B`, `#E5D2A7`, `#F4EADB`
- 강조: 구리색 `#A9653C`
- 상태: 절제된 녹색 / 안전 주황 / 제한된 파랑
- 색상만으로 상태를 전달하지 않고 텍스트와 형태를 함께 사용

### 아이콘

- 승인된 광물·재화·장갑·카트 아이콘을 작고 기능적으로 사용
- 보석 테두리, 등급 별, 가챠 배지 형태는 사용하지 않음
- 희귀도는 색상보다 숫자·기록 칸·잠금 문구로 전달

### 정보 구조

- `BlockProgramUI`: 작업대와 코드 편집기
- `MineHUD`: 창고 장부와 실행 상태 요약
- `MineInventoryUI`: 계정 원장·보호 수량·자동 판매 규칙
- `MineSelectUI`: 광산 노선표·강화 계약·입장 조건
- `AccountRecoveryUI`: 서버 운영 공지·저장본 비교

## 금지 목록

- 모바일 가챠 상점처럼 보이는 카드 캐러셀
- 거대한 둥근 컬러 버튼 행
- 광택이 강한 3D 금색 프레임
- 불필요한 영문 대문자 제목
- 기능과 관계없는 보석 반짝임·등급 장식

## 구현 시 유지할 계약

- 1920×1080 기준의 좌측 편집기·중앙 RectTile 광산·우측 HUD 구조
- 우측 상단 MSW 시스템 UI 예약 영역 회피
- 팝업은 별도 UI Group으로 유지하고 중앙 모달은 한 번에 하나만 표시
- 실제 `.ui` 구현은 UIBuilder로 수행하며, 이 문서는 시각 기준으로만 사용
