# 계정 복구 UI v3 생성 프롬프트

기존 `maple-digger-account-recovery-ui-concept-v2-workshop-1920x1080.png`를 기반으로 한다. `계정 복구`, `복구 후보를 찾았습니다.`, 복구 후보/마지막 정상 저장 비교 표, 마지막 정상 저장 유지 안내, `복구`·`포기`, `선택 전까지 플레이가 중지됩니다.`를 유지한다.

밝기를 약 40% 높여 크림색 종이와 밝힌 목재·슬레이트 프레임을 사용한다. 민트·하늘색 상태색, 친근한 방패/체크 아이콘, 테이프로 붙인 안내 메모 느낌을 더해 캐주얼함을 약 20% 추가한다. 오류 공포보다 안심되는 작업장 공지처럼 보여야 한다.

금색 광택, 가챠 문법, 보물상자, 카드 캐러셀, 거대한 광택 버튼, 네온, 과한 반짝임, 영어 중심 레이블은 금지한다. 표의 열과 한국어 문구는 선명하게 보이게 한다.
