# Maple-Digger MineSelectUI 시안 v2 — 작업장형 생성 기록

## 방향

광산 선택을 모바일 카드 캐러셀이 아니라 `광산 노선표`와 `강화 계약서`로 표현했다.

## 주요 표현

- 초보·깊은·보석 광산의 입장/해금 상태
- 대표 광물과 현재 레벨
- 4개 강화 효과의 현재값과 다음값
- 다음 강화 비용
- 특별 광맥 활성 수와 최근 셀 좌표
- 입장·강화·판매·수레·희귀 기록·튜토리얼 다시 보기

## 시각 규칙

- 왼쪽은 노선 목록, 오른쪽은 선택 광산 상세 장부
- 선택 상태는 파란 경로 표시로만 강조
- 잠금은 주황색 문구로 표시하고 별·등급 배지는 사용하지 않음
