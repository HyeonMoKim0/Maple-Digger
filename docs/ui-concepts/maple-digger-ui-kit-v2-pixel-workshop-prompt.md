# Maple-Digger Pixel Workshop UI Kit v2

## 목적

메인 플레이와 계정 창고 초안에서 확정한 도트 작업장 스타일을 반복 가능한 UI 부품으로 분리한다. 이 이미지는 실제 `.ui`를 통째로 대체하는 화면이 아니라, 개별 패널·버튼·아이콘을 제작하고 조합하기 위한 시각 기준이다.

## 보드 구성

- 패널: 대형 작업 프로그램 패널, 소형 광산 HUD
- 버튼 상태: 실행·정지·초기화·변환·입력·인벤토리·광산 선택의 기본/선택/비활성
- 명령 버튼: E/W/N/S, 채굴, 싣기, 내리기, 반복, 조건
- 탭·상태: 일꾼 탭, 실행/대기/차단/정지 점, 선택 일꾼 배지, 수레 용량
- 장부 행: 자원 행, 효과 행, 토글, 구분선
- 모달·토스트: 공통 프레임과 토스트 바
- 아이콘·팔레트: 광석·재화·도구 아이콘, 크림/베이지/목재/슬레이트/구리/하늘색/민트/주황/초록/빨강

## 제작 규칙

- 픽셀 스냅과 1~2px 어두운 외곽선
- 재질별 2~3단 명암, 제한된 흙색 팔레트
- 부품 사이에 충분한 여백을 두고 각각 잘라 사용할 수 있게 구성
- 둥근 3D bevel·페인터리 그라디언트·금속 스크래치·과한 광택은 사용하지 않음
- 캐주얼함은 상태색과 작은 광부 모티프에만 사용
- 실제 적용 시에는 이 보드를 참고해 UIBuilder로 개별 요소를 재구성하고, SpriteRUID·텍스트·상태 바인딩을 별도로 연결
