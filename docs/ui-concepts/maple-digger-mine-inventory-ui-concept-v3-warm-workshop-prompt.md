# 계정 창고 UI v3 생성 프롬프트

기존 `maple-digger-mine-inventory-ui-concept-v2-workshop-1920x1080.png`를 기반으로 한다. 중앙 `계정 창고` 장부, `일반 광물`, `희귀 광물 기록`, `자동 판매 규칙`, `적용 중 패시브`, 하단 `판매`·`보호량 설정`·`닫기` 구조와 수치를 유지한다.

밝기를 약 40% 높여 따뜻한 크림색 종이와 밝은 금속 프레임을 넓게 사용한다. 민트·하늘색·오렌지 선과 스위치로 상태를 구분하고, 모서리와 헤더를 조금 부드럽게 해 캐주얼함을 약 20% 추가한다. 한쪽에 작은 광부/광물 낙서 정도만 허용한다.

여전히 카드 모음이 아닌 실용적인 장부여야 한다. 가챠 별, 보물상자, 금색 광택, 네온, 과한 반짝임, 영어 중심 레이블은 금지한다.
