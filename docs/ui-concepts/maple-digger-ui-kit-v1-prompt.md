# Maple-Digger UI 키트 v1 생성 기록

## 목적

v2.2 밝은 메인 플레이 시안을 실제 UI 제작에 필요한 재사용 컴포넌트 단위로 분해하기 위한 아트 핸드오프 보드다. 이 파일과 PNG는 시각 기준이며, 최종 런타임 UI는 기존 MSW `.ui` 그룹과 `UIBuilder`를 통해 구성한다.

## 키트 구성

- `BlockProgramUI`용 대형 크림·골드 패널
- `MineHUD`용 소형 정보 패널
- Command / Run / Stop / Clear / Input / Mine Select / Inventory 버튼
- 선택·일반·비활성 탭 상태
- 단일 입력창과 다중 행 프로그램 입력창
- Toast 및 Modal 프레임
- Stone / Iron / Gold Ore / Gold / Crystal / Mine Token 리소스 아이콘
- 이동·채굴·적재·반복·조건·종료·변환·입력·실행 제어 아이콘
- 워커 상태 점, 선택 워커 배지
- 색상 팔레트와 Maple 계열 둥근 게임 폰트 적용을 위한 문자 샘플 영역

## 스타일 규칙

- 기본 표면: 밝은 크림·꿀색·금색
- 주요 액션: 하늘색, 녹색, 주황·빨강
- 보조 강조: 민트, 보라, 파랑 보석색
- 공통 외곽선: 짙은 갈색
- 공통 모서리: 둥근 사각형과 부드러운 bevel
- 아이콘: 작은 치비 광산 도구와 보석 형태, 동일한 외곽선 두께
- 텍스트: 실제 구현 시 Maple 계열 폰트와 한국어 로컬라이즈 텍스트로 교체

## 구현 연결

- 패널 키트 → `BlockProgramUI`, `MineHUD`, `MineInventoryUI`, `MineSelectUI`
- 토스트 키트 → `ToastGroup`
- 모달 키트 → `PopupGroup` 또는 화면별 전용 팝업
- 버튼·텍스트·아이콘은 한 장의 배경 이미지로 넣지 않고 개별 UI 요소로 재구성
- 앵커·피벗·`GroupOrder`·UUID 바인딩과 1920×1080 실제 플레이 검증을 수행

## 주의

생성 이미지의 문자와 아이콘은 시각 기준용이다. 실제 게임에서는 텍스트를 MSW UI 텍스트 컴포넌트로 분리하고, 아이콘은 개별 SpriteRUID 또는 프로젝트 리소스로 연결해야 한다. 패널과 버튼을 투명 개별 스프라이트로 사용할 경우에는 별도 추출·정리 단계가 필요하다.
