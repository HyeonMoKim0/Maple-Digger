# Maple-Digger AccountRecoveryUI 시안 v2 — 작업장형 생성 기록

## 방향

복구 화면을 판타지 경고 팝업이 아니라 서버 저장본을 비교하는 `운영 공지`로 표현했다.

## 주요 표현

- 복구 후보와 마지막 정상 저장본 비교
- 자동 재시도하지 않는다는 안내
- 포기해도 정상 저장본은 유지된다는 설명
- `복구`·`포기` 두 선택지만 제공

## 시각 규칙

- 전체 화면 차단 dim
- 얇은 철제 프레임과 작업지
- 작은 상태 아이콘과 표 형식 비교
- 닫기 버튼·추가 팝업·오류 전문은 표시하지 않음
