# 메인 플레이 UI v5 — 도트 작업장 초안

기존 `maple-digger-main-play-ui-concept-v4-warm-workshop-1920x1080.png`의 3단 구조를 유지한다. 좌측 `작업 프로그램`, 중앙 RectTile 광산 그리드와 좌표·광석·수레·광부, 우측 `초보 광산` 장부 HUD 및 `인벤토리`·`광산 선택` 버튼을 바꾸지 않는다.

스타일만 도트 게임에 맞게 변환한다. 픽셀 스냅, 제한된 흙색 팔레트, 재질별 2~3단 명암, 굵고 일정한 픽셀 외곽선, 단순한 목재·슬레이트·구리 프레임을 사용한다. 페인터리 그라디언트, 부드러운 bevel, 금속 스크래치, 광택은 제거한다. 밝은 크림 패널과 호박색 랜턴은 유지하고, 하늘색·민트·오렌지 포인트와 작은 광부 동작으로만 캐주얼함을 더한다.

가챠 별, 보물상자 프레임, 카드 캐러셀, 네온, 과한 반짝임, 영어 중심 UI는 금지한다. 1920×1080 가로 화면에서 모든 조작부가 보여야 한다.
