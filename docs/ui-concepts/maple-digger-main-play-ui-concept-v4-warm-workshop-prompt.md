# 메인 플레이 UI v4 생성 프롬프트

기존 `maple-digger-main-play-ui-concept-v3-workshop-1920x1080.png`를 기반으로, 작업장형 구조와 한국어 정보 계층을 유지한다. 좌측 `작업 프로그램`, 중앙 RectTile 광산 그리드와 좌표, 우측 `초보 광산` 장부 HUD, `인벤토리`, `광산 선택` 버튼을 그대로 둔다.

밝은 분위기를 약 40% 추가한다. 크림·파치먼트 면적을 키우고, 밝은 슬레이트·따뜻한 목재·구리·호박색 랜턴과 약한 낮빛을 사용한다. 캐주얼함은 약 20%만 추가한다. 둥근 명령 칩, 저채도 하늘색·민트·오렌지 포인트, 작은 광부의 친근한 동작을 허용한다.

금색 광택, 가챠 별, 보물상자 프레임, 카드 캐러셀, 거대한 광택 버튼, 네온, 과한 반짝임, 영어 중심 UI는 금지한다. 1920×1080 가로 화면에서 패널과 조작부를 모두 보이게 한다.
