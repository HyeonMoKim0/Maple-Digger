# Maple-Digger AccountRecoveryUI 시안 v1 생성 기록

## 목적

손상 복구 후보가 있을 때 플레이를 차단하고 사용자가 `Recover` 또는 `Give Up`을 명시적으로 선택하게 하는 `AccountRecoveryUI`의 1920×1080 시안이다.

## 근거 문서

- `docs/12-계정-프로필-저장-복구-기능명세.md` §3~§5
- `docs/08-비주얼-사운드-기능명세.md` §6.1~§6.2
- `docs/23-서버-거절-사유.md`의 `AccountRecoveryUI` 메시지 채널 구분

## 화면 구성

- 전체 화면 dim·blur 차단 오버레이
- 복구 후보와 마지막 정상 프로필의 비교 카드
- 자동 재시도하지 않는다는 안내
- `Give Up`을 선택해도 마지막 정상 프로필은 유지된다는 안내
- Recover / Give Up 두 버튼

## 시각 규칙

- 심각한 상태지만 공포스럽지 않은 밝은 크림·금색 계열을 유지한다.
- Recover는 녹색, Give Up은 주황·빨강, 정상 프로필은 청록색으로 구분한다.
- 선택 전에는 게임 조작이 차단되므로 닫기 버튼을 두지 않는다.

## 구현 경계

- 실제 오류 전문·스택 트레이스는 화면에 노출하지 않는다.
- 이 오버레이는 가장 높은 차단 계층을 유지하고 다른 모달·토스트와 겹치지 않게 한다.
- 복구 재시도는 사용자의 Recover 입력에서만 시작한다.
