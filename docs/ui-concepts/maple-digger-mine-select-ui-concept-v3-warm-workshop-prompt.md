# 광산 선택 UI v3 생성 프롬프트

기존 `maple-digger-mine-select-ui-concept-v2-workshop-1920x1080.png`를 기반으로 한다. 중앙 `광산 선택`, 좌측 `광산 목록`과 `초보 광산`·`깊은 광산`·`보석 광산` 경로, 우측 선택 광산의 현재/다음 효과와 비용, 하단 `입장`·`강화`·`판매`·`수레`·`희귀 기록`·`튜토리얼 다시 보기`·`닫기`를 유지한다.

밝기를 약 40% 높여 밝은 종이·목재·호박색 조명과 읽기 쉬운 대비를 사용한다. 경로 노드는 저채도 하늘색·민트·오렌지로 구분하고, 모서리와 아이콘을 조금 부드럽게 해 캐주얼함을 약 20% 추가한다. 경로판과 장부가 초보자에게 친근하게 읽혀야 한다.

카드 상점처럼 보이지 않게 한다. 금색 보상 프레임, 가챠 별, 보물상자, 네온 그라디언트, 거대한 광택 버튼, 과한 반짝임, 영어 중심 레이블은 금지한다.
