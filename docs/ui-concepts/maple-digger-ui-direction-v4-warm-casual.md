# Maple-Digger UI 방향 v4 — 밝은 작업장 + 절제된 캐주얼

## 적용 범위

- 대상: 메인 플레이, 계정 창고, 광산 선택, 계정 복구 UI 콘셉트
- 기준: v3 `workshop` 구조와 정보 우선순위 유지
- 변경량: 밝은 분위기 약 40% 추가, 캐주얼함 약 20% 추가

## 핵심 인상

`어두운 광산의 작업장`을 버리지 않고, 창구·장부·작업대에 따뜻한 조명을 더한다. 처음 보는 플레이어가 부담 없이 읽고 눌러 볼 수 있지만, 수집형 모바일 게임의 카드/등급/가챠 문법으로 보이지 않게 한다.

## 색과 재질

| 역할 | 방향 |
| --- | --- |
| 기본 면 | 크림·파치먼트 `#F0DEC0` ~ `#FFF3DC` |
| 구조물 | 밝힌 슬레이트, 따뜻한 목재, 구리 |
| 포인트 | 저채도 하늘색·민트·오렌지 |
| 조명 | 호박색 랜턴 + 약한 낮빛, 검정에 가까운 비네트 금지 |

## 캐주얼함의 한계

- 둥근 모서리, 짧은 명령 칩, 작은 광부 표정/동작은 허용
- 버튼은 평면 목재·도장 질감으로 유지
- 금색 광택 프레임, 가챠 별, 보물상자 장식, 카드 캐러셀, 네온 그라디언트, 과한 반짝임은 금지
- 한국어가 1차 레이블이며, 영문은 보조 표기만 사용

## 화면별 유지점

- 메인 플레이: 좌측 작업 프로그램 / 중앙 RectTile 광산 / 우측 장부 HUD 3단 구조
- 계정 창고: 일반 광물·희귀 기록·자동 판매 규칙·패시브를 한 장부에서 비교
- 광산 선택: 광산 목록과 연결된 경로 노드, 현재/다음 효과와 비용의 비교
- 계정 복구: 복구 후보와 마지막 정상 저장의 표 비교, 복구/포기 선택 전 플레이 중지

## 구현 시 체크

- [ ] 1920×1080에서 모든 주요 패널과 버튼이 잘리지 않는가
- [ ] 밝아졌지만 텍스트·광물 아이콘·상태 색의 대비가 유지되는가
- [ ] 캐주얼 요소가 정보 계층보다 앞서지 않는가
- [ ] 실제 UI의 GroupOrder와 버튼 명칭을 임의로 늘리지 않았는가
