# 계정 창고 UI v4 — 도트 작업장 초안

기존 `maple-digger-mine-inventory-ui-concept-v3-warm-workshop-1920x1080.png`의 중앙 `계정 창고` 장부 구조를 유지한다. `일반 광물`, `희귀 광물 기록`, `자동 판매 규칙`, `적용 중 패시브`, 광물 수치·토글, 하단 `판매`·`보호량 설정`·`닫기`를 그대로 둔다.

스타일만 도트 게임에 맞게 변환한다. 픽셀 스냅, 크림·목재·슬레이트·구리의 제한 팔레트, 2~3단 명암, 1~2px 픽셀 규칙선과 일관된 어두운 외곽선을 사용한다. 종이결·부드러운 그라디언트·광택 버튼·실제 금속 질감은 줄인다. 따뜻하고 밝은 장부 인상은 유지하고, 섹션별 하늘색·민트·오렌지 포인트와 작은 광부 표시만 추가한다.

카드 수집 화면처럼 보이지 않게 한다. 가챠 별, 보물상자, 네온, 과한 반짝임, 영어 중심 레이블은 금지한다. 모든 필드와 버튼은 1920×1080 안에서 선명하게 보이게 한다.
