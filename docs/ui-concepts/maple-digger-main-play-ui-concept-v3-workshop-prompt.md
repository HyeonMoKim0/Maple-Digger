# Maple-Digger 메인 플레이 UI 시안 v3 생성 기록

## 방향

금색·광택·카드형 모바일 UI 문법을 줄이고, 작업장·광산 장부·블록 자동화 도구의 인상을 강화했다.

## 유지한 구조

- 좌측 `BlockProgramUI` 작업 프로그램 편집기
- 중앙 RectTile 탑다운 광산과 워커·수레
- 우측 `MineHUD` 원장형 정보 패널
- 우측 하단 `인벤토리`·`광산 선택` 진입점

## 추가한 시각 언어

- 숯색 철판, 낡은 작업지, 목재, 구리 리벳
- 블록 명령 태그와 고정폭 프로그램 목록
- 셀 좌표와 선택 워커 경로 표시
- 승인 리소스 아이콘의 기능적 사용
- 한국어 중심 라벨

## 제외

- 보물상자형 금색 프레임
- 광택 베벨과 별·보석 반짝임
- 등급·가챠 카드 문법
- 불필요한 영문 대문자 메뉴
