# Maple-Digger 메인 플레이 UI 시안 v2.2 생성 기록

## 의도

v2.1의 기능 배치와 안전 여백을 그대로 유지하면서, 실제 Maple 계열의 둥글고 두꺼운 게임 폰트를 적용한다는 전제에 맞춰 화면을 더 밝고 귀엽게 보정한 시안이다.

## 변경한 시각 방향

- 어두운 갈색·검정 위주의 프레임을 크림·꿀색·밝은 금색으로 전환
- 명령 버튼과 광석을 하늘색·민트·주황·보라의 둥근 보석형 포인트로 보정
- 타일 광산, 랜턴, 광석에 밝은 하이라이트와 작은 반짝임 추가
- 작은 치비 광부와 두꺼운 외곽선, 친근한 아이콘 비율을 강화
- 실제 UI의 텍스트는 Maple 계열 폰트로 교체할 예정이며, 시안의 영문은 정보 밀도와 줄 길이를 확인하기 위한 임시 표기

## 유지한 구조

- 좌측: `BlockProgramUI`의 탭 1–5, 이동·채굴·적재·반복·조건 명령, 프로그램/입력/피드백, 실행 제어
- 중앙: RectTile 기반 탑다운 광산과 치비 워커
- 상단 중앙: 단일 특수 광맥 토스트
- 우측: `MineHUD`의 광산/광석/재화/선택 워커/손·카트/워커 상태 요약
- 우측 하단: `MineInventoryUI`, `MineSelectUI` 진입 버튼
- 우측 HUD는 MSW 데스크톱 화면의 우측 상단 예약 영역과 겹치지 않도록 안쪽·아래쪽에 유지

## 제외

- 하단 내비게이션
- Appearance, Programs 등 현재 구조에 없는 상시 메뉴
- 대형 캐릭터 초상, 스태미나 바, 타이틀/로고
- 중앙 모달을 메인 화면 위에 상시 합성하는 구성

## 구현 주의

이 이미지는 아트·정보 구조 레퍼런스다. 실제 제작에서는 기존 UI 루트별로 개별 패널·텍스트·버튼·아이콘을 `UIBuilder`로 구성하고, 앵커·피벗·`GroupOrder`·UUID 바인딩과 1920×1080 실제 플레이 화면을 검증한다.
