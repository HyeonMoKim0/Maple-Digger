# F5. 비주얼 · 사운드 기능 명세

> D5 구현 계약. 서버가 게임 결과를 확정하고, 클라이언트는 읽기 전용 동기화 상태와 중요한 이벤트를 시각화·재생한다.

## 1. 책임 분리

| 모듈 | 실행 위치 | 책임 | 금지 |
|---|---|---|---|
| `VeinTickSimulator` | ServerOnly, 맵 | 일반/특별 광맥 stage·회복·드롭 결과 | RUID 선택·효과음 |
| `WorkerController` | ServerOnly, 일꾼 | 이동·채굴·적재·하역 결과, 행동 이벤트 발행 | 클라이언트 효과 직접 생성 |
| `VeinMarkerController` | ClientOnly, 일반 marker | oreType·stage에 따른 렌더링 | stage 변경·회복 계산 |
| `SpecialVeinMarkerController` | ClientOnly, 특별 marker | 스폰/위치/강조 연출 | 스폰 확률·최대 수 판정 |
| `WorkerVisualController` | ClientOnly, 일꾼 | 선택 링·행동 효과·아바타 표시 | 프로그램·수레·창고 변경 |
| `MineSoundController` | ClientOnly, 맵 | cue 재생과 쿨다운 | 게임 이벤트 판정 |
| `MineInventoryController` | ClientOnly, HUD | 광물·재화·수레·상태 표시 | 자원 변경 |

## 2. 동기화와 이벤트

### 2.1 일반 광맥 marker

| 이름 | 타입 | 작성자 | 의미 |
|---|---|---|---|
| `VeinId` | string | 맵 설정 | D6 논리 ID |
| `ReserveStage` | integer | 서버 | 0~3 현재 stage |
| `OreType` | string | 서버/설정 | `stone`/`iron`/`gold` |
| `VisualRevision` | integer | 서버 | stage 또는 oreType 변경마다 증가 |

`OreType × ReserveStage`로 승인된 RUID를 선택한다. RUID가 누락되면 마지막 유효 스프라이트를 유지하고 ID 포함 오류를 남긴다. 빈 RUID는 사용하지 않는다.

### 2.2 행동·중요 이벤트

일꾼은 `VisualEventSequence`, `VisualEventKind`, `VisualEventCellX/Y`를 제공한다. 종류는 `move`, `mine_success`, `mine_fail`, `load_success`, `unload_success`다. 클라이언트는 아직 처리하지 않은 sequence만 한 번 처리한다.

희귀 입고와 특별 광맥 출현은 일반 행동 scalar와 분리한 **중요 이벤트 채널**을 쓴다. 이벤트에는 단조 증가 ID, `kind`, `mineId`, 위치, 광물/보상 요약을 포함한다. 재접속/지연 때 중복 재생하지 않되, UI가 놓치면 HUD 현재 상태로 복구 가능해야 한다.

| 중요 kind | 필수 반응 |
|---|---|
| `special_vein_spawn` | 월드 전용 marker, 토스트, 지도 위치, HUD 아이콘, cue 1회 |
| `rare_ore_unload` | Depot 강조, 희귀 광물·패시브 HUD 갱신, cue 1회 |
| `sale_completed` | 골드/크리스탈 변화 강조. 자동화는 계속 진행 |
| `appearance_obtained` | 피스·희귀도·도감 변화 표시 |

## 3. 렌더링 규칙

- stage 0은 고갈 형태, 1~3은 증가하는 광석 크기·광택으로 표현한다. 0→1/1→2/2→3은 0.25초 회복 효과 1회다.
- `mine_success`는 해당 일꾼 위치 파편과 `mine_hit`, `unload_success`는 Depot 강조와 HUD 수치 강조를 같은 sequence에서 각 1회 실행한다.
- 특별 광맥 marker는 활성 목록에서 제거되면 즉시 연출을 취소한다.
- 선택 링은 프로그램 편집기의 선택 WorkerIndex와 일치한다. HUD는 최대 5명 상태를 그리되, 상세 손/수레는 선택 일꾼을 우선 표시한다.
- 모든 임시 파티클·타이머·사운드 핸들은 map unload에서 정리한다.

## 4. 사운드 재생 규칙

| cue | 이벤트 | 쿨다운 |
|---|---|---|
| `mine_hit` | `mine_success` | 일꾼별 0.25초 |
| `mine_empty` | `mine_fail` | 선택 일꾼별 0.8초 |
| `cart_load` | `load_success` | 일꾼별 0.25초 |
| `depot_unload` | `unload_success` | 전역 1틱 1회 |
| `special_vein_spawn` | 중요 이벤트 | 스폰 묶음당 1회 |
| `rare_ore_unload` | 중요 이벤트 | 이벤트 ID당 1회 |

미승인 cue/RUID는 무음·무효과로 안전하게 건너뛰며 서버 시뮬레이션을 멈추지 않는다.

## 5. HUD 표시 계약

> 신설: 2026-07-30. D3 §7과 D5 §4에 기획 서술로 흩어져 있던 HUD 요구사항을 **필드 단위 구현 계약**으로 고정한다. 이 절이 `MineHUD.ui` / `MineInventoryUI.ui` / `MineInventoryController`의 단일 기준이다. 계약 없이 화면을 고쳐 같은 누락이 재발한 사례가 `docs/16` §7.3 D-2다.

### 5.1 `MineHUD` — 상시 표시 필수 필드

10개 필드는 **모두 표시한다.** 값이 0이거나 미구현이어도 필드를 숨기지 않는다. 숨기면 "표시했는지 누락인지" 검수로 구분할 수 없다.

| # | 필드 | 표시 형식 예 | 데이터 출처(`@Sync`) | 갱신 시점 |
|:-:|---|---|---|---|
| H1 | 현재 광산 이름 | `초보 광산` | `MineLayoutConfig.MineId` → 표시 이름 매핑. 폴백은 `LocalPlayer.CurrentMap` | 맵 진입·전환 |
| H2 | 맵 강화 레벨 | `Lv.0 / 10` | v8 `AccountProfileService.MineLevelBeginner/Deep/Gem` | 강화 성공·맵 전환 |
| H3 | 계정 창고 돌 | `돌 128` | **`AccountProfileService.Stone`** | 하역·판매 |
| H4 | 계정 창고 철 | `철 40` | **`AccountProfileService.Iron`** | 하역·판매 |
| H5 | 계정 창고 금 | `금 3` | **`AccountProfileService.GoldOre`** | 하역·판매 |
| H6 | 골드 | `골드 1,240` | `AccountProfileService.Gold` | 판매·구매·강화 |
| H7 | 크리스탈 | `크리스탈 0` | v8 `AccountProfileService.Crystal` | 획득·가챠 |
| H8 | 광산 토큰 | `토큰 6` | `AccountProfileService.MineTokens` | 판매·해금 |
| H9 | 선택 일꾼 손 | `일꾼 1 손: 돌 ×2` | `WorkerController.PendingOre` + v8 `PendingOreCount` | 매 틱 |
| H10 | 일꾼별 실행 상태 | `1 Running / 2 Idle` | `WorkerController.ProgramState` × `AccountProfileService.OwnedWorkerCount` | 상태 전이 |

선택 일꾼의 수레는 H9와 같은 행 묶음으로 `일꾼 1 수레: 12 / 22`를 표시한다(`CartCount` / `CartCapacity`).

**출처 규칙 — 창고는 계정 원장이다.** H3~H5는 `VeinTickSimulator.DepotStone/DepotIron/DepotGold`(세션 하역 합계)를 쓰지 않는다. 세션 합계를 함께 보여 주려면 `이번 세션 하역` 같은 **다른 라벨의 별도 행**으로 분리해, 계정 보유량과 혼동되지 않게 한다.

**미구현 필드의 처리.** H2·H7은 프로필 v7에 아직 필드가 없다.

| 필드 | v8 전 처리 | v8 후 |
|---|---|---|
| H2 맵 강화 레벨 | 세 맵 모두 실제로 레벨 0이므로 `Lv.0 / 10`을 **상수로 표시**한다 | `MineLevel*` `@Sync` 값 연결 |
| H7 크리스탈 | 획득 경로(F7-D)도 미구현이라 실제 보유는 0이다. `크리스탈 0`을 **상수로 표시**한다 | `Crystal` `@Sync` 값 연결 |

상수 표시는 값이 사실과 일치하는 동안만 허용하는 임시 조치다. 두 필드를 `@Sync`로 바꾸는 작업은 F7-B 맵 강화 구현(v8 마이그레이션)과 같은 단위에서 처리한다.

### 5.2 `MineInventoryUI` — 팝업 표시 필수 필드

| # | 필드 | 데이터 출처 |
|:-:|---|---|
| I1 | 계정 창고 돌·철·금 상세 | `Stone` / `Iron` / `GoldOre` |
| I2 | 희귀 컬렉션 3종 단계 | `RareStoneCollectionLevel` / `RareIronCollectionLevel` / `RareGoldCollectionLevel` (각 `n/10`) |
| I3 | 희귀 보관 수량 3종 | `RareStoneStored` / `RareIronStored` / `RareGoldStored` |
| I4 | 희귀 판매 잠금 상태 | 컬렉션 단계 10 미달이면 `판매 잠김` |
| I5 | 적용 중인 희귀 패시브 | 단계 × 3%를 종류별로 표시 (수레 용량 / 회복 속도 / 판매 가격) |
| I6 | 일반 광물 자동 판매·보호 수량 | `*AutoSell` / `*ProtectedAmount` |

도감 점수·수레 도감 보너스는 F7-D 구현 뒤 I7로 추가한다.

### 5.3 갱신 규칙

- `OnUpdate` 폴링 + 변경 감지 방식을 유지한다. **비교 키에는 이 계약의 모든 필드를 포함한다** — 키에서 빠진 필드는 값이 바뀌어도 화면이 갱신되지 않는다(무증상 실패).
- 서버 값이 `nil`이면 마지막 유효 텍스트를 유지하고 필드를 비우지 않는다.
- 클라이언트는 서버 값을 재계산·보정하지 않는다. 특히 **수레 용량의 희귀 돌 보너스는 `floor(기본 × 단계 × 3 / 100)` 버림이라 단계마다 +1칸이 아니다**(관측값 20, 21, 21, 22, 23, 23, 24, 24, 25, 26). 서버가 준 값을 그대로 표시한다.
- 선택 일꾼 인덱스는 **프로그램 편집기의 선택값(`_BlockProgramController`)을 단일 기준으로 따른다.** HUD가 인덱스를 상수로 고정하면 F5 §3의 "선택 링은 편집기의 선택 WorkerIndex와 일치" 규칙이 깨진다.

## 6. 화면 영역 분할 규칙

> 신설: 2026-07-30. 기준 해상도 PC 1920×1080, 캔버스 중심 원점 `(0, 0)`. D-1(버튼이 헤더를 가림)·D-3(패널 과점유)의 재발 방지 계약이며, 근거 결정은 D8 **C201**이다.

### 6.1 영역 소유권

| 영역 | 소유 화면 | 폭·위치 | 상시/조건 |
|---|---|---|---|
| 좌측 명령 영역 | `BlockProgramUI/Panel` | 폭 **최대 640px**(화면 1/3). 좌측 정렬 | 상시, **토글로 접힘 가능** |
| 우측 상단 정보 영역 | `MineHUD/Panel` | 우측 상단 | 상시 |
| 우측 버튼 스택 | `MineSelectUI/BtnOpen` 등 화면 열기 버튼 | HUD 아래로 세로 정렬 | 상시 |
| 중앙 모달 영역 | `MineSelectUI`의 `SelectPanel` / `SalePanel` / `CartPanel` / `RarePanel`, 향후 맵 강화·외형·가챠 패널 | 중앙 | 열릴 때만 |
| 전체 차단 오버레이 | `AccountRecoveryUI` | 전체 + dimmer | 복구·세션 차단 시 |
| 월드 가시 영역 | 게임 월드 | 편집기 접힘 시 전체. 펼침 시 x ≥ -320 | 상시 |

**상시 표시 요소는 서로 겹치지 않는다.** 겹침이 관측되면 검수 실패로 판정한다. 열기 버튼은 좌측 640px 영역을 침범할 수 없다.

### 6.2 `displayOrder` 계층

| 계층 | 값 | 대상 |
|---|:--:|---|
| 월드 | — | 월드 엔티티 |
| 상시 HUD | 10 | `MineHUD` |
| 상시 패널 | 20 | `BlockProgramUI` |
| 모달 패널 | 30 | 광산 선택·판매·수레 강화·맵 강화·외형·가챠 |
| 팝업 | 40 | 희귀 판매 팝업, 인벤토리 팝업, 확인 팝업 |
| 토스트 | 50 | `ToastGroup` |
| 차단 오버레이 | 60 | `AccountRecoveryUI` |

같은 계층 안에서는 형제 간 `displayOrder`가 중복되지 않게 둔다. 새 화면을 추가할 때 계층을 먼저 고른 뒤 그 계층 범위 안에서 값을 정한다.

### 6.3 편집기 토글

- 편집기 패널에는 접기/펼치기 토글을 제공한다. 접힌 상태에서는 토글 버튼만 남고 월드를 가리지 않는다.
- 접힘/펼침은 표시 상태일 뿐이며 실행 중인 프로그램에 영향을 주지 않는다.
- 토글 상태는 계정 저장 대상이 아니다. 세션마다 펼친 상태로 시작한다.
