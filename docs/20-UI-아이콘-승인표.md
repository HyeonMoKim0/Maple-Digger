## 1. 이 문서의 목적

현재 HUD와 인벤토리 팝업은 **전부 텍스트**다. D5 §7이 아이콘을 요구하지만 승인 목록과 RUID가 없어 T-08이 막혀 있었다. 이 문서가 그 목록이다.

**승인 절차**: 아래 후보 중 하나를 골라 `승인` 열에 표시 → T-08이 그 RUID를 `SpriteGUIRendererComponent.ImageRUID`에 적용한다.

## 2. 선정 기준

| 기준 | 값 |
|---|---|
| 최소 크기 | **24×24 이상** (D5 §7). 아래 후보는 전부 충족 |
| 리소스 타입 | **`sprite`** — 개별 정적 이미지. `animationclip`을 넣으면 프레임이 재생돼 UI에서 산만해진다 |
| 검색 경로 | `msw-search` → `searchResources(resourceTypeFilter: ["sprite"], categoryFilter: ["item"])` |
| 적용 대상 | `SpriteGUIRendererComponent.ImageRUID` (UI 전용). 월드 렌더러의 `SpriteRUID`와 혼용하지 않는다 |

> **`thumbnail://` 접두어는 붙이지 않는다.** 아래는 전부 `sprite` 타입이라 RUID를 그대로 넣으면 렌더된다. 접두어는 `avataritem` / `skeleton` / `animationclip`을 정적 썸네일로 그릴 때만 쓴다.

## 6. 실행 상태 (F5 §5.1 H10) — 아이콘 대신 텍스트를 권한다

`Idle` / `Running` / `Blocked` / `Stopped` 4상태에 맞는 적절한 아이콘을 찾지 못했다. 검색된 후보(`미스 표시`, `빠직마크` 등)는 전투용 이펙트라 의미가 맞지 않는다.

**권고**: 실행 상태는 **아이콘 없이 텍스트 + 색**으로 처리한다.

| 상태 | 표기 | 색 |
|---|---|---|
| `Running` | `Running` | 녹색 |
| `Idle` | `Idle` | 회색 |
| `Blocked` | `Blocked` | 주황 |
| `Stopped` | `Stopped` | 적색 |

색만으로 구분하지 않고 **텍스트를 함께 두는 것**이 D5 §8 V1의 "색 외의 형태로 구분" 원칙과도 맞는다. 아이콘이 꼭 필요하면 `msw-painter`로 4개를 직접 그리는 방법이 있다(별도 티켓).
--> 나: 그대로 하자.

## 7. 미결 사항

| # | 항목 | 결정 |
|:-:|---|---|
| 1 | `작업용 카트`(32×16)의 24px 미달 | **✅ 확정 (오너)** — 24px 기준의 **예외로 허용**한다. 세로를 강제로 늘리거나 원본 비율을 유지하는 두 방법 중 **원본 비율 유지**를 기본으로 한다(늘리면 카트가 찌그러져 의미가 오히려 흐려진다). 구현: 슬롯은 24×24로 두고 `PreserveSprite = AspectOnly(1)`을 써서 비율을 지킨 채 폭에 맞춘다. 결과적으로 32×16 원본이 24×12로 그려지고 위아래 여백이 생긴다. 이것이 어색하면 슬롯을 32×24로 넓히고 같은 설정을 쓴다 |
| 2 | 희귀 광물 3종 아이콘 (F5 §5.2 I2~I5) | **후순위.** 일반 광물 아이콘을 재사용하며 색조·테두리로 구분하거나 별도 검색한다. 현재 인벤토리 팝업은 텍스트로 충분히 읽힌다 |
| 3 | 아이콘 배치 규격 | HUD 각 행의 텍스트 왼쪽에 **24×24 고정 슬롯**. 행 높이 32~34px에 수직 중앙 정렬. `작업용 카트`만 미결 1의 예외를 적용 |
| 4 | 9-슬라이스·pivot | 아이콘은 단순 이미지라 **`ImageType = Simple(0)`** 으로 충분하다. 9-슬라이스는 패널 배경에만 쓴다 |

## 8. T-08 적용 시 주의

- `SpriteGUIRendererComponent`를 새로 붙일 때 **`ImageRUID`를 비워 두면 아무것도 안 보인다**(오류 없음). 반드시 승인된 RUID를 넣는다.
- 아이콘 슬롯을 추가하면 **행 폭이 줄어든다.** HUD 패널은 460×430이고 콘텐츠 폭이 428이므로, 24px 슬롯 + 8px 간격을 빼면 텍스트 폭이 396으로 줄어든다. 현재 문구가 잘리지 않는지 확인할 것.
- 패널 내부는 F5 §6.1대로 **`top-center` + pivot `(0.5,1)` 단일 좌표계**를 유지한다.
- 작업 후 `node tools/audit_bindings.cjs`로 바인딩을 확인한다.
