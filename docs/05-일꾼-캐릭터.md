# D4. 일꾼 · 캐릭터 기획서 (MVP 통합)

> 최신 결정 기준: [10-MVP-성장-경제-통합명세.md](10-MVP-성장-경제-통합명세.md) (D7). 자원 흐름은 [04-자원-인벤토리.md](04-자원-인벤토리.md), 프로그램 계약은 [03-블록명령-명세.md](03-블록명령-명세.md)를 따른다.

## 1. 목표와 범위

플레이어는 일꾼에게 블록 프로그램을 실행시켜 광물을 운반하고, 성장을 통해 **시작 1명에서 최대 5명**의 일꾼을 확보한다. 외형은 수집·제작·무료 가챠의 장기 목표이며, 모든 일꾼이 보유 외형을 자유롭게 사용한다.

- 포함: 일꾼 획득, 일꾼별 실행/손/수레/프로그램, 수레 강화, 외형 저장·장착, 프로그램 라이브러리 연동, 계정 저장·복구
- 제외: MVP 유료 가챠/BM, 일꾼 간 충돌 예약, 길찾기, 다중 플레이어 자원 공유

## 2. 기본 규칙

| 항목 | 확정 규칙 |
|---|---|
| 시작/최대 일꾼 | 1명 시작, 최대 5명 |
| 소유 | 일꾼·외형·프로그램은 계정 소유 및 영구 저장 |
| 광산 진입 | 한 계정은 한 번에 선택한 광산 하나에서만 작업 |
| 광산 전환 | 모든 일꾼 프로그램을 정지. 새 광산에서는 항상 수동 실행 |
| 접속 복구 | 마지막 광산 입장 후 HUD 상태를 잠시 보이고, 마지막 유효 프로그램을 자동 실행 |
| 셀 겹침 | 허용. 충돌 예약·교착 방지는 MVP 제외 |
| 일꾼 차이 | MVP 기본 성능 차이는 수레 용량뿐. 외형 희귀도/수레 보너스 확장은 이후 판단 |

## 3. 일꾼별 상태와 계정 공용 상태

| 상태 | 소유 | 저장 |
|---|---|---|
| 현재 셀, 프로그램 스택, 실행 상태 | 일꾼별 | 계정 저장 |
| 손의 광물, 수레 내용·용량·강화 레벨 | 일꾼별 | 계정 저장 |
| 착용 헤어/얼굴/의상 | 일꾼별 장착 값 | 계정 저장 |
| 일반/희귀 광물, 재화, 맵 해금·강화 | 계정 공용 | 계정 저장 |
| 프로그램 라이브러리, 보유 외형, 도감 점수 | 계정 공용 | 계정 저장 |
| 광맥 stage, 특별 광맥 | 현재 광산 세션 | 세션 종료 시 초기화 |

실행기는 등록된 일꾼마다 틱당 최대 액션 1개를 처리한다. 한 일꾼의 명령 실패·수레 만재는 다른 일꾼의 틱을 소비하지 않는다.

## 4. 수레 성장과 구매

- 기본 수레 용량은 20칸이며, 일꾼별 강화로 2칸씩 증가하여 최대 50칸이다.
- 강화 비용은 골드와 해당 맵 일반 광물이다. MVP에서는 낮게 두고 테스트 후 조정한다.
- 외형 도감 점수 보너스는 모든 일꾼 수레에 +1칸씩 추가되며, 강화 최대 50과 별도로 누적된다.
- 신규 일꾼은 새 맵/광물 진행에 따라 열리고, 골드와 특정 일반 광물 납품을 요구한다. 첫 추가 일꾼은 튜토리얼의 판매 직후 5분 내 목표로 제시한다.

초안 구매값은 D7의 밸런스 표를 따른다. 변경 시에도 ‘새 맵/광물 진행으로 해금 → 골드+광물 납품으로 구매’ 순서는 유지한다.

## 5. 프로그램 배정 UX

1. 플레이어는 대상 일꾼을 선택한다.
2. 편집기 또는 프로그램 라이브러리에서 프로그램을 선택한다.
3. 실행 전 대상 일꾼과 프로그램 내용을 확인한다.
4. 유효성 검사를 통과하면 해당 일꾼에게 실행한다.
5. 프로그램 오류는 자동 수정하지 않고 수정안을 제시한다.

HUD는 최대 5명 모두의 `Idle/Running/Blocked/Stopped` 상태를 보여 준다. 선택 일꾼의 손·수레와 계정 창고는 함께 표시한다. 프로그램 라이브러리는 계정 공용이며, 슬롯은 3개에서 시작해 골드로 최대 20개까지 확장한다(구매마다 가격 1.2배).

## 6. 외형·도감

### 외형 구조

- 부위는 헤어, 얼굴, 의상 3개다. 기본 외형은 영구 저장하며 언제든 무료로 되돌릴 수 있다.
- 부위별 피스는 일반 3, 고급 3, 희귀 2, 영웅 1, 전설 1로 총 10개씩 준비한다.
- 각 피스는 희귀도를 개별 보유한다. 보유 피스는 모든 일꾼이 공유하여 자유롭게 조합한다.
- 중복 피스는 골드 보상으로 전환한다. 제작 결과도 랜덤이다.

### 획득과 도감

- 광물 조합 제작 또는 플레이 중 얻은 무료 크리스탈로 획득한다. MVP의 크리스탈은 테스트 상점·과제 등 무료 지급만 제공하며 실제 결제는 제외한다.
- 가챠는 헤어/얼굴/의상 중 플레이어가 고른 부위에서 실행한다. 확률은 일반 50%, 고급 30%, 희귀 15%, 영웅 4%, 전설 1%다.
- 세 부위는 하나의 50회 카운터를 공유한다. 50번째에는 플레이어가 부위를 지정해 전설 피스를 확정 획득한다.
- 새 피스 최초 획득만 도감 점수(일반~전설 1~5점)에 반영한다. 일정 점수마다 모든 일꾼 수레 +1칸을 부여한다.

## 7. 외형 화면과 시각 우선순위

- 외형 화면에는 부위별 보유 피스, 희귀도, 제작 재료, 가챠 확률, 공유 50회 카운터, 도감 보너스를 표시한다.
- MVP 시각 목표는 MSW 아바타 랜덤 조합까지다. 최초 획득, 전설, 장착 변경만 강조 이펙트를 표시하고 반복 동작은 생략 가능하다.
- 외형 자체가 수레 성능을 바꾸는 규칙은 후속 검토 대상이다. 현재 확정 성능 보너스는 도감 점수뿐이다.

## 8. 저장·실패 처리

- 일꾼 구매·수레 강화·외형 획득·프로그램 변경은 중요 거래로 즉시 저장한다. 그 외에도 주기 저장, 맵 이동, 종료 시 저장한다.
- 중요 저장 실패는 거래를 취소하고 비용을 환불한다.
- 같은 계정의 동시 접속은 새 접속을 막고 “다른 기기에서 플레이 중입니다”만 표시한다.
- 복구 실패는 사용자에게 복구/포기를 묻고, 복구 선택 시에만 재시도한다.

## 9. MVP 수용 기준

| # | 시나리오 | 기대 결과 |
|---|---|---|
| W1 | 새 계정 시작 | 일꾼 1명, 골드 0, 기본 프로그램 1개 |
| W2 | 판매 후 두 번째 일꾼 구매 | 비용·납품 차감, 두 일꾼이 독립 실행 |
| W3 | 최대 5명에 서로 다른 프로그램 실행 | 일꾼당 1틱 1액션, 다른 일꾼 실패가 전파되지 않음 |
| W4 | 수레 강화 | 20에서 +2씩, 50까지 증가; 도감 보너스는 별도 적용 |
| W5 | 광산 전환 | 모든 일꾼 정지, 전환한 맵에서는 수동 실행 필요 |
| W6 | 재접속 | 일꾼/수레/프로그램/외형을 복구하고 마지막 유효 프로그램 자동 실행 |
| W7 | 외형 피스 획득·중복 | 계정 공용 장착 가능, 중복은 골드 전환 |
| W8 | 50회 가챠 | 공유 카운터가 부위 지정 전설 피스를 지급 |
