## 각 문서의 필수 수록 내용

### D0. 용어·테마 전환 명세 (가장 먼저, 반나절 분량)
모든 후속 문서와 코드 리스킨의 기준. **이 문서 없이는 기획서와 코드의 용어가 계속 어긋난다.**
- 농사→광산 개념 매핑표: 작물→광물, 심기→(광맥 노출/시추), 수확→채굴, 성장 stage→매장량 회복 단계, 드론→일꾼 캐릭터
- 코드 심볼 리네임 대상표: `FarmTickSimulator`→`VeinTickSimulator`, `DroneController`→`WorkerController`, `Farm/` 폴더명, 블록 라벨(H→M 등), 로그 프리픽스
- 확정 용어 사전(한글 표기 + 코드 영문 표기 병기) — 채팅 파서 키워드("캐", "실어")도 여기서 확정

### D1. 마스터 GDD (전체 조망)
- 계정 성장 루프: 블록 자동화 → 광맥/창고 → 판매·강화 → 일꾼/광산/외형 확장
- 세 광산, 1→5명 일꾼, 영구 저장, 프로그램 라이브러리, 외형·도감의 관계와 화면 목록
- 프로토타입 구현 상태와 앞으로의 MVP 수용 기준을 구분

### D2. 블록 명령 체계 명세서 (③단계 — 프로그래머 최우선 전달)
- **블록 카탈로그 전체표**: 이동(E/W/N/S), 채굴, 운반(싣기/내리기), **반복(횟수 지정)**, **조건(IF 광물 있음/없음, 수레 가득참)** — 각 블록의 파라미터, UI 라벨, 채팅 키워드
- **실행 모델 정의**: 틱당 1액션 유지, 반복 블록의 처리 방식(조립 시 전개 vs 런타임 인터프리트 — 권장안 명시), 중첩 허용 깊이
- **안전 규칙**: 프로그램 최대 길이, 무한루프 방지(최대 실행 틱), 맵 경계 처리, 실행 중 재실행 시 동작
- ~~채팅 자연어 확장·입력 연결~~ — T-14에서 MVP 제거. 폐지 전 계약은 `docs/03` §6·§8과 git 이력에만 보존한다.
- 수용 기준(acceptance criteria): "반복 3회 E이동 후 IF광물→채굴 프로그램이 로그로 검증됨" 같은 테스트 시나리오 목록

### D3. 자원·인벤토리 기획서
- 돌·철·금 및 희귀 돌·철·금, 계정 창고와 판매·자동 판매·보호 수량
- 채굴→손→수레→Depot→계정 창고 흐름, 희귀 패시브, 즉시 저장/복구 계약

### D4. 일꾼 캐릭터 기획서
- 일꾼 1명 시작·최대 5명, 수레 20→50 강화, 프로그램·외형·복구 규칙
- 헤어/얼굴/의상 피스, 무료 가챠·도감 보너스, 계정 공용 외형

### D5. 비주얼·사운드 폴리싱 가이드
- 돌·철·금 stage, 특별 광맥, 희귀 입고, 다중 일꾼과 외형 화면의 정보 우선순위

### D6. 광산 맵·콘텐츠 배치 기획서
- 초보/깊은/보석 3맵의 레이아웃, 일반·특별 광맥, 최대 5명 시작점, marker 검증

### F5/F6. 기능 명세
