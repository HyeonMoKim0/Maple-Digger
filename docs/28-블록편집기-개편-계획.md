## 2. 블록 스트립 그리드 — "칸 하나 = 블록 하나"

### 2.1 표시 계약

- `ProgramText` 줄글을 **정사각 셀 그리드**로 교체한다. 프로그램의 **평탄 토큰 순서**(팔레트가 넣는 순서 그대로 — `반복`·`IF`·`끝]` 도 각각 한 칸)를 왼쪽 위부터 채운다. 중첩 들여쓰기를 그리지 않는다 — 괄호 칸(`반복`~`끝]`)이 이미 구조를 말한다.
- 셀 표기 = **문자 + 계열 틴트** (docs/20 §6 — 그림 단독 금지): `동``서``남``북`(슬레이트) · `채``적``하`(녹색 계열) · `반``×2``IF``끝`(주황 계열) · 조건 칸 `조`. 팔레트 버튼과 같은 문구 첫 글자라 학습 비용 0.
- 셀 배경은 **`command-tile-slate-blank`**(192×187 정사각, 업로드 완료·미사용 — docs/26 §5.2 "정사각 아이콘 버튼이 생기면 그때 쓴다"의 그 용처다). 계열 구분은 틴트.
- **선택 일꾼의 실행 중 스텝 강조(선택)**: `Running` 중 현재 스텝 셀 테두리 강조 — F5 §3 선택 링과 같은 "지금 뭘 하는지" 축. 구현 여유 있을 때 (U4).

### 2.2 크기·수용량 (제안)

자연어 3요소 제거로 **-534 ~ -790 (약 256px 높이 × 592px 폭)** 이 그리드 영역이 된다.

| 항목 | 제안 |
|---|---|
| 셀 | **56×56**, 간격 6 → 한 행 9칸 (9×62-6=552 ≤ 592) |
| 행 | **4행 = 36칸** (4×62-6=242 ≤ 256) |
| 초과 | 37칸째부터는 마지막 칸을 **`+N`** 표기로 접는다 (블록 수 상한은 검증기 계약 확인 후 — 상한이 36 이하면 접기 자체가 불필요) |
| 구현 | GridView 가 아니라 **고정 풀 36칸을 `.ui` 에 미리 만들고 런타임 스왑** — 워커 탭·상태 램프·광산 노드와 같은 검증된 패턴. 빈 칸은 Enable=false |

### 2.3 상호작용 (제안 — U2)

- **셀 클릭 = 그 블록 삭제.** 지금은 전체 `초기화`뿐이라 중간 실수 하나에 처음부터 다시 조립한다(D-17 사고의 원인이 "실수 복구 불가"였다). 셀 하나가 곧 삭제 버튼이 되면 별도 UI 없이 해결된다.
- 제어 블록 시작 칸(`반복`/`IF`)을 삭제하면 **그 짝 `끝]`까지의 몸통을 함께 삭제**한다 — 괄호 짝이 깨진 상태를 만들지 않는다 (검증기·직렬화 계약 보호, D-17 §1 주의사항 12-1 계열).
- 편집은 지금처럼 **클라이언트 로컬**이고 서버 검증은 Run 시점 `ValidateProgram` 단일 소유 그대로 (F7-C).
