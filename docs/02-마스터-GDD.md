# D1. 메이플 디거 — 마스터 게임 디자인 문서

> 최신화: 2026-07-29
> 세부 구현 계약은 D2(블록), D3(자원·경제), D4(일꾼·외형), D5/F5(시각·사운드), D6/F6(광산·맵), D7/F7-A~D(계정 성장), D8(결정 이력)을 따른다. 충돌 시 D7과 D8의 최신 결정을 우선한다.

## 1. 게임 한 줄 정의

**텍스트 코딩 없이 블록 조립 또는 한국어 문장으로 일꾼 자동화를 설계하고, 광물 판매·맵 해금·외형 수집으로 계정을 성장시키는 탑다운 광산 자동화 게임.**

- 플랫폼: MapleStory Worlds, Top-down RectTile(`TileMapMode=1`)
- 목표 경험: “내가 만든 프로그램이 광산을 더 효율적으로 굴린다”는 자동화 설계의 재미
- 우선 플랫폼: PC 1920×1080
- MVP 플레이 방식: 한 계정이 한 번에 하나의 광산에서 최대 5명의 일꾼을 운용

## 2. 핵심 루프

```text
[설계]  블록 조립 / 자연어 변환 / 라이브러리에서 프로그램 선택
   ↓
[실행]  일꾼이 이동 → 채굴 → 적재 → 맵 창고 하역
   ↓
[축적]  계정 창고에 돌·철·금 및 희귀 광물 누적
   ↓
[판매]  일반 광물을 골드·광산 토큰으로 전환
   ↓
[성장]  일꾼·수레·광산 강화, 다음 광산 해금, 외형 수집
   ↓
[개선]  더 효율적인 프로그램과 동선을 설계
```

광맥 회복은 현재 세션 안에서만 지속한다. 오프라인 보상은 MVP 범위에 넣지 않는다.

### 서버·클라이언트·저장 경계

- 서버는 광맥, 자원 거래, 프로그램 검증, 희귀 패시브, 해금/강화의 권위 있는 결과를 계산한다.
- 클라이언트는 프로그램 편집, 화면 전환, HUD, 마커/효과/사운드만 담당하며 자원을 변경하지 않는다.
- 계정 저장은 중요 거래에서 즉시 쓰고, 자동 저장·맵 이동·종료 시에도 저장한다.
- 저장 실패한 구매/강화는 완료 처리하지 않고 비용을 반환한다.

| 2 | 계정 저장 + 경제 | 기본 프로필 저장, 소유 일꾼별 손·수레/마지막 광산 복구, 정상 백업 복구/포기, 동시 접속 잠금, 보호 판매, 광산 첫 해금, 일꾼 2~5 구매와 수레 강화가 동작 |
| 3 | 성장 확장 | 최대 5 일꾼, 맵 강화, 특별·희귀 광맥이 동작 |
| 4 | 외형 | 피스/도감/제작/무료 가챠가 동작 |

## 6. 고정 설계 결정

1. Tick은 0.4초, 일꾼당 Tick당 최대 1액션이다.
2. 인터프리터와 모든 자원·거래 판정은 서버에서 실행한다.
3. 자연어 변환은 외부 API 없이 규칙 기반으로 동작한다.
4. 모든 광산은 RectTile(`TileMapMode=1`)이며 일꾼은 `KinematicbodyComponent` 기반이다.
5. 계정 데이터는 플레이어별로 영구 저장한다. 광맥 stage와 특별 광맥만 세션 전용이다.
6. 시작 일꾼은 1명, 최대 운용 일꾼은 5명이다.
7. 한 번에 하나의 광산에서 모든 일꾼이 작업하며, 맵 전환 시 프로그램은 모두 정지한다.
8. 실제 현금 결제·오프라인 보상은 MVP에서 제외한다.
9. PC 우선 UI를 유지한다.

## 7. 현재 구현 기준점

D2 핵심, D3 프로토타입, D4-A의 Maker 검증 기록은 유효한 기반이다. 다만 D4-A의 2일꾼은 과거 프로토타입이며, 현재 MVP 시작 상태는 `Worker01` 한 명이다. F6의 3광산 JSON 레이아웃·marker·특별 광맥, F7-A의 계정 복구/잠금, F7-B의 계정 광물 원장·수량/보호/자동 판매·첫 해금·일꾼 2~5 구매·일꾼별 수레 20→50 강화·희귀 컬렉션/판매는 구현·Maker 검증됐다. F7-A/B는 v7 프로필에서 소유 일꾼별 손·수레·강화 레벨과 마지막 광산, 희귀 컬렉션/보관/자동 판매 설정, 정상 백업 복구/포기, 만료형 동시 접속 잠금까지 구현한다. F5 연출, F7-B의 맵 강화, F7-C/D는 아직 구현·Play 검증이 필요하다. 실제 상태는 `Archive/As-built.md`, 직접 조작·시각 검수는 `16-사용자-검수-체크리스트.md`, 최신 목표는 D7과 F7-A~D, 질문 원문은 D8에서 확인한다.
