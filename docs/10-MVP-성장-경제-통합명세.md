# D7. 메이플 디거 — MVP 성장·경제·계정 통합 명세

> 작성일: 2026-07-26, 구현 계약 분할: 2026-07-27
> 상태: 구현 기준 확정. 수치 표 중 **초기 테스트 제안**으로 표시한 값은 Play 테스트 후 조정한다.  
> 선행 문서: D1 마스터 GDD, D3 자원·인벤토리, D4 일꾼, D5 비주얼·사운드, D6 광산 맵·콘텐츠, F5/F6 기능 명세. 구현 시에는 F7-A(저장), F7-B(경제), F7-C(프로그램·세션), F7-D(외형)를 각각 따른다.

## 1. MVP 목표와 범위

메이플 디거의 MVP는 계정 성장형 자동화 광산 게임이다. 플레이어는 블록 프로그램으로 일꾼을 자동화하여 광물을 채굴·판매하고, 새 일꾼과 광산을 해금한다. 수집한 외형 피스는 일꾼에게 장착할 수 있으며, 도감 점수는 모든 일꾼의 수레 용량에 보너스를 준다.

### 1.1 최종 시연의 핵심 흐름

`튜토리얼 → 자동화 → 광물 판매 → 두 번째 일꾼 구매`

MVP 최종 검증에는 다음 기능도 포함한다.

- 초보/깊은/보석 광산 3개 해금과 이동
- 수동 판매와 임계값 기반 자동 판매
- 최대 5명 일꾼 구매 및 수레 강화
- 계정 저장, 재접속 자동화, 저장 복구
- 외형 제작·무료 크리스탈 가챠·도감 수레 보너스
- 광맥·일꾼·창고의 시각·사운드 피드백

### 1.2 MVP 제외 또는 후순위

- 실제 현금 결제 및 유료 크리스탈 구매
- 오프라인 보상
- 멀티플레이 자원/일꾼 공유
- Data 초기화 UI
- 일일·주간 과제: 기본 기능 완료 뒤 여유가 있을 때만 구현
- 일정 부족 시 후순위: 일일·주간 과제 → 외형 가챠 → 외형 제작

## 2. 고정 세계 규칙

| 항목 | 결정 |
|---|---|
| 기본 시뮬레이션 | 0.4초 Tick, 일꾼당 Tick당 최대 액션 1개 |
| 시작 일꾼 | 1명 |
| 일꾼 최대 보유/운용 수 | 5명 |
| 일꾼 기본 성능 차이 | 없음. 수레는 모두 기본 20칸 |
| 일꾼 성장 | 수레를 골드+광물로 강화, 기본 20칸에서 최대 50칸까지 2칸씩 증가 |
| 일꾼 외형 | 헤어·얼굴·의상 피스를 자유 조합. 보유 피스는 모든 일꾼이 동시에 장착 가능 |
| 맵 운용 | 한 번에 선택한 하나의 광산에서 모든 일꾼이 작업 |
| 맵 이동 | 게임 진행 화면의 광산 선택 메뉴에서 수행. 맵 전환 시 모든 일꾼 프로그램 정지 |
| 재접속 | 마지막 플레이 광산으로 돌아오며, HUD를 잠시 표시한 뒤 각 일꾼의 마지막 유효 프로그램을 처음부터 자동 실행 |
| 잘못된 자동 프로그램 | 마지막 유효 프로그램을 찾아 실행. 없으면 Idle 및 원인 안내 |

## 3. 계정·세션 저장 정책

### 3.1 계정별 영구 저장 대상

플레이어별로 독립 저장한다. 같은 계정의 동시 접속은 차단하며, 새 접속에는 “다른 기기에서 플레이 중입니다”를 표시한다.

| 범주 | 저장 대상 |
|---|---|
| 화폐 | `Gold`, `Crystal`, `MineToken` |
| 진행 | 해금 맵, 마지막 플레이 맵, 맵별 강화 레벨, 튜토리얼 진행도 |
| 자원 | 계정 창고의 돌/철/금 및 희귀 광물 수량 |
| 일꾼 | Worker ID, 기본 외형, 장착 외형, 수레 강화 레벨, 손·수레 상태, 마지막 유효 프로그램 참조 |
| 프로그램 | 계정 공용 라이브러리, 슬롯 확장 상태, 프로그램 이름/블록 구조/버전 |
| 외형 | 보유 헤어·얼굴·의상 피스, 도감 점수, 가챠 천장 카운터 |
| 희귀 성장 | 희귀 돌·철·금의 창고 하역 등록 횟수, 희귀 광물 컬렉션과 각 패시브 누적 단계 |
| 설정 | 광물별 자동 판매 여부, 보호 수량, 특별 광맥/자동화 알림 설정 |

### 3.2 세션 전용 상태

일반 광맥의 stage, 회복 경과, 특별 광맥의 위치·활성 상태는 현재 Play 세션에서만 유지한다. 재접속 또는 세션 종료 시 초기화한다. 특별 광맥은 시간 만료로 사라지지 않고 세션 종료 또는 맵 이탈 때만 제거한다.

창고, 일꾼 손, 수레는 계정 저장 대상이다. 맵을 바꿔도 계정 창고에 남은 광물은 유지한다.

### 3.3 저장·복구 규칙

- 광물 판매, 일꾼 구매, 수레 강화, 맵 해금/강화, 외형 획득/장착, 프로그램 저장/삭제는 즉시 저장한다.
- 추가로 일정 시간 자동 저장과 맵 이동/종료 시 저장을 수행한다.
- 저장 실패 시 중요 거래는 즉시 취소하고 비용을 반환한다.
- 다음 접속에 복구 후보가 있으면 플레이어에게 `복구` 또는 `포기`를 제시한다. 복구는 사용자가 재시도 버튼을 눌렀을 때만 다시 시도한다.
- 데이터 구조가 업데이트되면 기존 저장을 백업한 뒤 버전 변환을 시도한다.

## 4. 광산과 맵 진행

### 4.1 광산 목록

| 순서 | 광산 | 일반 광물 | 자동화 핵심 | 주 강화 효과 |
|---:|---|---|---|---|
| 1 | 초보 광산 | 돌 | 단순 왕복 | 광물 획득량 |
| 2 | 깊은 광산 | 돌 + 철 | 철 광맥까지 긴 이동 | 광맥 회복 속도 |
| 3 | 보석 광산 | 돌 + 철 + 금 | 여러 광물의 효율적 루트 구축 | 희귀 광물 확률 |

맵은 갈수록 넓어진다. 모든 맵은 명시적인 상하좌우 이동 블록만으로 해결 가능하며, 길찾기는 MVP 범위에 넣지 않는다.

### 4.2 맵 해금과 강화

- 광산 입장 자체에는 반복 소모 비용이 없다.
- 토큰은 다음 맵 해금 조건 충족용이며, 골드는 실제 비용이다.
- 맵 해금에는 골드 + 토큰 + 특정 일반 광물 납품이 필요하다.
- 각 맵은 **레벨 0에서 10까지** 영구 강화한다(C197). 해금 직후가 레벨 0이며 보너스가 0이고, 총 10회 강화한다.
- 레벨당 주 효과는 +3%를 기준으로 하며, 나머지 세 효과에는 +1%의 작은 보너스를 적용한다. 따라서 레벨 10에서 주 효과 +30%, 나머지 각 +10%다.
- 맵 강화 비용은 골드 + 해당 맵의 대표 일반 광물이다. 대표 광물은 초보 `stone`, 깊은 `iron`, 보석 `gold`다.

맵 강화의 구현 계약(효과별 계산 방식, 희귀 패시브와의 합성, 저장 스키마, 서버 API, 수용 테스트)은 [13-경제-진행-기능명세.md](13-경제-진행-기능명세.md) §5가 단일 기준이다.

### 4.3 특별 광맥과 희귀 광물

| 항목 | 결정 |
|---|---|
| 출현 | 약 5분마다 1~2개 생성. 진행도/맵 강화에 따라 주기 단축 가능 |
| 동시 존재 | 맵 전체 최대 3개 |
| 유지 | 현재 세션 동안 유지, 세션 종료 시 초기화 |
| 외형 | 전용 스프라이트·반짝임·효과음 |
| 통지 | 토스트 + 위치 표시 + HUD 아이콘 |
| 희귀 판정 | 일반 광맥 채굴 1회당 1%, 특별 광맥 채굴 1회당 5% |
| 희귀 종류 | 희귀 돌·철·금 각 1종 |
| 획득 흐름 | 손 → 수레 → 창고. 창고 하역 순간 패시브 획득으로 확정 |
| 자동화 | 희귀 광물을 획득해도 자동화는 중단하지 않음 |

희귀 광물은 창고 하역 순간 외형 도감과 별도인 희귀 광물 컬렉션에 등록된다. 등록으로만 계정 패시브가 누적되며, 판매는 능력치 획득 조건이 아니다. 각 종류는 최대 10단계까지 누적하고, 10단계 전에는 수동·자동 판매가 모두 불가능하다. 11회째부터 플레이어가 자동 판매를 켜거나 수동 판매할 수 있으며, 판매 보상은 희귀 돌 50골드·희귀 철 200골드·희귀 금 600골드다.

희귀 패시브는 계정 전체에 적용한다. 희귀 돌은 수레 용량, 희귀 철은 광맥 회복 속도, 희귀 금은 일반 광물 판매 가격을 각각 강화하며, 희귀 광물 확률은 맵 강화 전용 효과다. 각 단계 효과는 +3%다.

## 5. 화폐·판매·경제

### 5.1 화폐

| 화폐 | 획득 | 사용 |
|---|---|---|
| 골드 | 일반 광물 판매, 중복 외형 전환, 과제 보상 | 일꾼 구매, 수레 강화, 맵 해금/강화, 프로그램 슬롯 |
| 크리스탈 | 튜토리얼, 특별 광맥 보상, 과제, MVP 테스트 상점 무료 지급 | 외형 가챠 |
| 광산 토큰 | 이전 광산의 대표 광물 판매, 주간 과제 등 | 다음 맵 해금 조건 충족 |

MVP에서는 실제 현금 구매를 제공하지 않는다. 테스트 상점에서 무료 크리스탈을 지급하여 가챠 흐름을 검증한다.

### 5.2 판매

- 돌/철/금 일반 광물은 수동 판매 및 자동 판매 대상이다.
- 수동 판매는 수량 입력과 `1/10/100/전량` 빠른 버튼을 모두 제공한다.
- 판매 화면은 보유 수량, 기본 단가, 보너스가 반영된 실제 단가, 판매 후 골드 총량을 표시한다.
- 초기 단가 제안: 돌 1골드, 철 5골드, 금 20골드.
- 자동 판매는 플레이어가 종류별로 설정하며, 지정한 보호 수량을 넘는 초과분만 판매한다.
- 다음 맵 해금에 필요한 일반 광물은 정확히 필요 수량만 보호한다. 플레이어가 보호분 판매를 원하면 경고 후 허용한다.
- 희귀 광물은 종류별 컬렉션 10단계 전에는 자동 판매 대상이 될 수 없다.

### 5.3 초기 테스트 경제 제안

아래 값은 10~15분 내 깊은 광산 해금, 약 5분 내 두 번째 일꾼 획득을 목표로 한 첫 Play 테스트 값이다.

| 대상 | 골드 | 토큰 | 납품 광물 | 해금 조건 |
|---|---:|---:|---|---|
| 일꾼 2 | 60 | - | - | 초보 광산 |
| 일꾼 3 | 200 | - | 돌 80 | 깊은 광산 해금 |
| 일꾼 4 | 650 | - | 돌 160 + 철 50 | 보석 광산 해금 |
| 일꾼 5 | 1,600 | - | 돌 300 + 철 120 + 금 30 | 보석 광산 해금 |
| 깊은 광산 | 180 | 6 | 돌 120 | 초보 광산 진행 |
| 보석 광산 | 700 | 10 | 돌 200 + 철 60 | 깊은 광산 진행 |

토큰의 첫 제안은 해당 이전 맵의 대표 광물 20개 판매당 1개다. 초보 광산은 돌, 깊은 광산은 철을 대표 광물로 사용한다.

수레 강화는 20에서 시작해 +2칸씩 최대 50까지 올린다. 첫 테스트 비용은 강화 단계 `n`에 대해 골드 `round(20 × 1.25^(n-1))`와 대표 광물 `5 × n`개를 사용한다.

맵 강화는 레벨 `L`에서 `L+1`로 올릴 때 `n = L + 1`(1~10)로 두고 골드 `round(30 × 1.35^(n-1))`와 대표 광물 `20 × n`개를 사용한다. 레벨 0→1이 골드 30 + 광물 20이고, 레벨 9→10이 골드 447 + 광물 200이다. 레벨 0에서 10까지의 누적 비용은 골드 약 1,638 + 대표 광물 1,100개다.

모든 광산은 광물 획득량·광맥 회복·희귀 광물 확률·특별 광맥 출현 가속의 네 효과를 가진다. 초보/깊은/보석 광산의 주 효과는 각각 획득량/회복/희귀 확률에 레벨당 +3%를 적용하고, 나머지 세 효과에는 +1%를 적용하는 것을 초기안으로 둔다. 특별 광맥 출현 가속은 기본 5분 대기 시간을 누적 보너스 비율만큼 단축하는 방식으로 계산한다. 효과별 정확한 계산식과 희귀 패시브와의 합성 규칙은 F7-B §5.3에 있다.

## 6. 일꾼·프로그램 라이브러리

### 6.1 일꾼

- 새 일꾼은 기본 외형, 기본 수레, 빈 프로그램으로 지급한다.
- 일꾼 성능의 기본 차이는 없고, 수레 강화와 계정 도감 보너스가 용량을 올린다.
- 외형 피스 보유는 계정 단위이며, 하나의 피스를 모든 일꾼에게 동시에 장착할 수 있다.

### 6.2 프로그램 라이브러리

프로그램 라이브러리는 계정 공용 “블록 설계도 보관함”이다. 저장 프로그램에는 이름, 블록 구조, 수정일, 데이터 버전을 기록한다. 라이브러리에서 선택한 프로그램은 대상 일꾼에게 복사되어, 대상·내용 확인 후 실행된다.

| 항목 | 결정 |
|---|---|
| 초기/최대 슬롯 | 3개 / 20개 |
| 슬롯 확장 | 골드 구매, 각 구매 비용은 직전 비용의 1.2배 |
| 이름 | 최대 12자, 한글·영문·숫자 |
| MVP 관리 | 이름 변경, 복제, 삭제 |
| 제한 위반 | 자동 수정하지 않고 문제와 수정안을 제안 |

## 7. 외형·도감·가챠

### 7.1 외형 피스

| 부위 | 총 수 | 일반 | 고급 | 희귀 | 영웅 | 전설 |
|---|---:|---:|---:|---:|---:|---:|
| 헤어 | 10 | 3 | 3 | 2 | 1 | 1 |
| 얼굴 | 10 | 3 | 3 | 2 | 1 | 1 |
| 의상 | 10 | 3 | 3 | 2 | 1 | 1 |

각 피스는 개별 희귀도를 가진다. 중복 피스는 희귀도가 높을수록 더 많은 골드로 전환하며, 도감 점수는 첫 획득 때만 더한다. 초기 외형으로의 복귀는 항상 무료다.

도감 점수는 일반/고급/희귀/영웅/전설 순서로 1/2/3/4/5점이다. 일정 점수마다 모든 일꾼 수레에 +1칸을 더한다. 기본 수레 강화 최대 50칸과 도감 보너스는 별도로 합산한다.

### 7.2 크리스탈 가챠

- 플레이어는 헤어/얼굴/의상 중 하나의 가챠 풀을 선택해 뽑는다.
- 확률: 일반 50%, 고급 30%, 희귀 15%, 영웅 4%, 전설 1%.
- 천장 카운터는 세 부위가 하나의 계정 공용 50회 카운터를 공유한다.
- 50번째 뽑기에서는 플레이어가 원하는 부위를 고르고, 그 부위의 전설 피스를 지급한다.
- 광물 조합 제작도 랜덤 피스를 지급하며, 중복 시 골드로 전환한다.
- MVP 가챠 비용은 낮은 테스트 값으로 시작하며, 실제 비용은 크리스탈 획득량과 함께 Play 테스트로 확정한다.

외형 희귀도는 도감 보너스를 통해 수레 용량에 영향을 준다. 이 구조는 향후 유료 크리스탈을 도입할 경우 성능에 영향을 줄 수 있으므로, 실제 유료화 전에 별도 BM·공정성 검토를 수행한다.

## 8. 튜토리얼과 과제

### 8.1 튜토리얼

순서: `이동 → 채굴 → 적재 → 하역 → 반복 → 조건 → 판매 → 일꾼 구매`.

튜토리얼은 스킵할 수 있고 나중에 다시 볼 수 있다. 완료 보상은 골드, 크리스탈, 기본 프로그램 1개다. 첫 테스트 수치 제안은 골드 20, 크리스탈 25다.

### 8.2 일일·주간 과제

기본 기능 완료 뒤 여유 범위로 둔다.

| 구분 | 개수 | 내용 | 보상 | 갱신 |
|---|---:|---|---|---|
| 일일 | 3 | 채굴량 / 판매량 / 프로그램 실행 | 골드 + 광물 | 한국 시간 05:00 |
| 주간 | 3 | 누적 판매 / 특별 광맥 / 긴 프로그램 완주 | 골드 + 광물 + 크리스탈 + 토큰 | 한국 시간 05:00의 주간 기준 |

모든 플레이어는 같은 과제와 난이도를 받는다. 일일 과제만 하루 1회 무료 교체할 수 있으며, 이후 교체에는 골드를 사용한다.

## 9. 광산 레이아웃 초안

아래는 Maker 오서링 전의 셀 기반 초안이다. 실제 타일 크기·유효 셀은 MapBuilder/Maker 검증으로 확정한다.

| 맵 | 권장 규모 | 창고/시작 구역 | 일반 광맥 동선 | 특별 광맥 후보 |
|---|---|---|---|---|
| 초보 광산 | 약 8×6셀 | 창고 `(0,0)`, 시작점 인접 | 돌 광맥 4개를 1~3셀 왕복 범위에 배치 | 외곽의 빈 이동 가능 셀 |
| 깊은 광산 | 약 14×8셀 | 창고 `(0,0)` | 돌은 창고 근처, 철은 6~10셀 떨어진 깊은 구역 | 철 광맥 주변과 갈림길 끝 |
| 보석 광산 | 약 20×12셀 | 창고 `(0,0)` | 돌 근거리, 철 중거리, 금은 가장 먼 두 갈래 구역 | 금 구역·중앙 교차로·위험 없는 외곽 |

초보 광산은 단순 왕복, 깊은 광산은 긴 철 운반, 보석 광산은 여러 광물 간의 효율 루트 설계를 학습시키는 데 집중한다.

## 10. 구현 순서와 수용 기준

### 10.1 목표 순서

1. D6: 3개 맵의 `MineLayoutConfig`, marker, 유효성 검사, 맵 선택/전환 기반
2. 계정 저장: 화폐·창고·일꾼·프로그램·맵 진행과 거래 저장/복구
3. 경제: 판매, 골드·토큰, 맵 해금, 두 번째 일꾼 구매
4. 확장: 나머지 일꾼, 수레/맵 강화, 특별·희귀 광맥
5. 외형: 피스·도감·제작·무료 크리스탈 가챠
6. D5: 광맥/일꾼/창고 비주얼·사운드 폴리싱
7. 여유 범위: 일일·주간 과제
