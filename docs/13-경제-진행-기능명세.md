# F7-B. 경제 · 진행 기능 명세

> D3/D7의 판매·보호 수량·광산 진행·일꾼/수레 강화 계약을 구현 책임으로 분리한다. 모든 수량과 비용 판정은 서버가 수행하며, 영구 반영은 F7-A를 통해서만 한다.

## 1. 구성 요소와 책임

| 구성 요소 | 책임 |
|---|---|
| `EconomyService` | 판매 단가, 골드·토큰 지급, 보호 수량·자동 판매 판정 |
| `ProgressionService` | 광산 해금/강화, 일꾼 구매, 수레 강화 조건과 비용 |
| `AccountProfileService` | 성공한 거래의 영구 저장과 실패 시 롤백 |
| 클라이언트 상점/HUD | 현재 보유량·조건·예상 결과를 표시하고 요청만 전송 |

## 2. 판매와 자동 판매

- 일반 광물 `stone`/`iron`/`gold`만 수동·자동 판매 대상이다. 초기 단가는 각각 1/5/20 골드이며 Play 테스트 전 제안값이다.
- 수동 판매는 수량 입력과 `1/10/100/전량`을 제공한다. 서버는 요청 수량이 보유량을 넘지 않는지 확인한다.
- 자동 판매는 광물별 토글과 보호 수량을 사용한다. 보호 수량 초과분만 판매한다.
- 다음 광산 해금에 필요한 일반 광물은 정확히 필요 수량만 보호한다. 보호분 판매 요청은 경고 확인 뒤 허용한다.
- 희귀 광물은 해당 종류 5회 입고 전 판매할 수 없다. 6회째부터 플레이어가 설정했을 때만 판매하며, 골드와 크리스탈 조각을 지급한다.

판매 보상, 토큰 전환, 자동 판매 여부는 서버가 하나의 거래로 계산·저장한다. UI는 성공한 결과만 강조한다.

## 3. 진행과 강화

| 항목 | 확정 규칙 |
|---|---|
| 광산 해금 | 골드 + MineToken + 특정 일반 광물 납품, 입장 반복 비용 없음 |
| 광산 강화 | 맵별 레벨 1~10, 골드 + 해당 대표 광물 |
| 일꾼 구매 | 1명 시작, 최대 5명; 골드와 진행 조건/광물 납품 |
| 수레 강화 | 일꾼별 기본 20에서 +2씩 최대 50, 골드 + 대표 광물 |
| 도감 보너스 | 수레 강화 최대치와 별도 합산; F7-D가 계산한 값을 사용 |

D7의 비용 표는 첫 Play 테스트 제안이다. 값을 바꿀 때는 D7과 D8 변경 기록을 함께 갱신한다.

## 4. 광산 전환

1. 서버는 해금 여부를 검증한다.
2. 현재 광산의 모든 일꾼 프로그램을 먼저 정지한다.
3. F7-A가 보존할 계정 상태를 저장하고, F6이 새 맵 레이아웃을 시작한다.
4. 새 맵의 일꾼은 시작점에서 Idle로 대기한다. 자동 실행하지 않는다.

현재 광맥 stage와 특별 광맥은 새 맵으로 전달하거나 저장하지 않는다.
