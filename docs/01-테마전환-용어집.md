# D0. 테마 전환 명세 · 용어집 (농사 → 광산)

> 2026-07-12 작성. 모든 후속 기획서(D1~D5)와 코드 리스킨은 이 문서의 용어를 기준으로 한다.
> 대상 독자: 프로그래머(이정택). 표의 "코드 영문 표기"가 스크립트/데이터의 공식 명칭이다.

## 1. 확정 용어 사전

| 한글 용어 | 코드 영문 표기 | 정의 |
|---|---|---|
| 광산 | Mine | 그리드 기반 플레이 맵 전체 |
| 셀 | Cell | 그리드 한 칸. 좌표 `(x,y)` |
| 광맥 | Vein | 광물이 매장된 셀. 시간이 지나면 매장량이 회복됨 |
| 광물 | Ore | 채굴로 얻는 자원 (종류 테이블은 D3에서 확정) |
| 매장량 단계 | ReserveStage | 광맥의 현재 상태. `0=고갈 ~ 3=만재` (기존 코드의 성장 stage 재활용). 채굴 1회당 **−1**(0에서 멈춤), 회복 주기마다 **+1**(3에서 멈춤). 상세는 D3 §4 |
| 일꾼 | Worker | 플레이어가 프로그램을 배정하는 자동화 캐릭터 (구 "드론") |
| 수레 | Cart | 일꾼이 광물을 담는 휴대 적재함 (용량 규칙은 D3) |
| 창고 | Depot | 광물을 최종 저장하는 고정 시설 셀 |
| 블록 | Block | 프로그램을 구성하는 명령 단위 |
| 프로그램 | Program | 블록의 순서·중첩 구조. 일꾼 1명에 1개 배정 |
| 틱 | Tick | 시뮬레이션 최소 시간 단위. 현재 0.4초 |

## 2. 농사 → 광산 개념 매핑표

| 기존(농사) | 신규(광산) | 처리 |
|---|---|---|
| 작물(crop) | 광물(ore) | 이름 교체 |
| 성장 stage 0→3 (자람) | 매장량 ReserveStage 0→3 (회복) | 틱 회복 로직 재활용("주기마다 +1, 3에서 정지"). **단, 채굴로 인한 −1 감소 경로는 신규 추가** (D3 §3) |
| 수확(harvest) | 채굴(mine) | 액션 교체. 채굴 시 해당 셀 ReserveStage **−1** (D2 §2 / D3 §4) |
| 심기(plant) | **삭제** | 광맥은 자연 회복이므로 심기 개념 없음. 대신 `싣기(load)`/`내리기(unload)` 액션 신설 (D2) |
| moisture(수분) | **삭제** | 미사용 필드 제거 |
| 드론(Drone) | 일꾼(Worker) | 이름 교체 |

## 3. 코드 심볼 리네임 대상표

| 현재 | 변경 후 | 비고 |
|---|---|---|
| `RootDesk/MyDesk/Farm/` 폴더 | `RootDesk/MyDesk/Mine/` | 이동 후 Maker refresh 필요 |
| `FarmTickSimulator.mlua` | `VeinTickSimulator.mlua` | `FarmState` → `VeinState`, 키는 `"x,y"` 유지 |
| `DroneController.mlua` | `WorkerController.mlua` | `RunProgram` RPC 이름은 유지 |
| `BlockProgramController.mlua` | (유지) | 테마 중립적이므로 이름 유지, 내부 라벨만 교체 |
| 로그 프리픽스 `[FarmTick]` / `[Drone]` | `[VeinTick]` / `[Worker]` | `[BlockProgram]` `[ChatParse]`는 유지 |
| `map/farm01.map` | (당분간 유지) | 맵 파일명 변경은 참조 깨짐 위험이 있어 Maker 에디터에서 수동으로만. 우선순위 낮음 |
| 블록 라벨 `H`(수확) | `M`(채굴) | UI 표시 문자 |
| 블록 라벨 `P`(심기) | 삭제 → `L`(싣기) / `U`(내리기) 신설 | D2에서 확정 |

## 4. 채팅(자연어) 키워드 전환

`ParseChatCommand`의 행동어 인식 규칙 교체 기준. 방향어("오른/왼/위/아래/동서남북")와 수사("두 칸", "3번")는 기존 규칙 유지.

| 기존 키워드 | 신규 키워드(부분 일치) | 매핑 블록 |
|---|---|---|
| "수확" | "캐", "채굴" | mine |
| "심" | **삭제** | — |
| (신규) | "실어", "싣", "담아" | load |
| (신규) | "내려", "비워" | unload |
| (신규) | "반복", "번 반복" | repeat (D2 §6) |
| (신규) | "있으면", "가득 차면", "없으면" | if 조건 (D2 §6) |

## 5. 적용 순서 (프로그래머 참고)

1. 폴더/파일 리네임 + 심볼 교체 (본 문서 §3) → Maker refresh → 기존 시나리오 회귀 확인 (틱 성장 로그, 5커맨드 큐 실행)
2. plant 액션 제거, load/unload 스텁 추가 (동작 정의는 D2·D3)
3. 채팅 키워드 교체 (§4) — repeat/if 매핑은 D2 인터프리터 구현과 함께
